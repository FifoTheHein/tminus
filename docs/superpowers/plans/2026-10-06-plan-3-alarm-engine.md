# Plan 3: Native Alarm Engine Implementation Plan

> **Execution (decided 2026-10-06): subagent-driven, using the orchestrator pattern.** Do not execute this plan inline. Run `/orchestrate` in plan mode on this plan to produce an orchestration plan (workers: `dev-worker`, `review-worker`, `deep-review`, `scout`), then run that orchestration plan with `/orchestrate <path>` in a fresh session. Each task here becomes one or more orchestrator jobs; its code and tests are the job's brief content. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the native Kotlin alarm engine (persistent plan, AlarmManager scheduling, ringing service, Compose alarm screen, notifications, re-arm triggers) and the typed Dart client for the `alarm_engine` channel, plus debug test buttons so it can be tried on a device before Plans 4 and 5 exist.

**Architecture:** Dart sends a `PlannedAlert` list over the `alarm_engine` MethodChannel. Kotlin keeps one JSON state file in device-protected storage (`PlanStore`) and diffs each new plan against it (`PlanDiff`), so only changed alarms are cancelled or armed (`AlarmScheduler`). There is **one AlarmManager alarm per alert**, and coalescing happens when an alarm fires: `EngineReducer.fire` collects every scheduled alert in the same `coalesceGroup`. Alarm-strength alerts ring in a `mediaPlayback` foreground service (`RingingService`) with a full-screen Compose `AlarmActivity`; heads-up alerts are high-importance notifications. User actions go through `EngineActions`, which updates state, AlarmManager, the event queue (`EventQueue` + EventChannel) and the UI.

**Tech Stack:** Kotlin 2.4.0 (AGP 9.1.0, Gradle 9.3.1, as generated by Flutter 3.47), Jetpack Compose (foundation only, BOM 2026.06.01), `org.json`, Robolectric 4.17 + JUnit 4.13.2, AndroidX Test for instrumented tests; Dart 3.13 / Flutter 3.47, `get_it`, `flutter_test`.

**Spec:** `docs/superpowers/specs/2026-10-06-tminus-design.md` (§6 Alarm behaviour, §7, §9, §11). Binding cross-plan contract: `docs/superpowers/plans/2026-10-06-tminus-roadmap.md` §3 and §5. Visuals: `docs/design-brief.md` §9–§10, mockups `docs/design/1b-alarm-dark.png`, `1c-alarm-coalesced.png`, `6f-alarm-light.png`, `6a-notifications.png`, `design-system.png`.

## Review Focus

1. **Force stop or a cleared alarm while the plan is unchanged.** After `adb shell am force-stop` Android drops every alarm and PendingIntent, but the next `applyPlan` sees the same ids and times. Expect the engine to notice the missing PendingIntent and arm it again (Task 5 test `a kept alert whose alarm vanished is armed again`; `MainActivity` also calls `rearmAll()` on start).
2. **Exact-alarm access revoked.** On Android 12–13, or after the user revokes it, `setAlarmClock` throws `SecurityException`. Expect an inexact allow-while-idle alarm, not a crash and not a silent drop (Task 5 test `without exact-alarm access alerts still get an inexact alarm`). On API 33+ `USE_EXACT_ALARM` is granted and cannot be revoked, so on the API 36 reference emulator (Task 15) this is covered by the Robolectric test only. A manual check needs an API 31–32 AVD: `adb shell appops set io.github.fifothehein.tminus SCHEDULE_EXACT_ALARM deny`, then **Test alarm**.
3. **A snooze choice that is already in the past** ("At start" on a coalesced screen where one meeting has already started, or a notification tapped late). Expect +1 min, never a snooze alarm in the past that fires instantly (Task 9 test `a past option snoozes for one minute instead`).
4. **The foreground service may not start** (`ForegroundServiceStartNotAllowedException` on Android 12+ outside the exact-alarm exemption, OEM quirks). Expect the alert to still appear as a heads-up notification (Task 12 test `if the ringing service cannot start the alert is posted as a heads-up`).
5. **Missing font assets** (renamed in `pubspec.yaml`, a build flavour without Flutter assets). The alarm screen must still render in system fonts, never crash (Task 11 tests `missing font files fall back to the system families` and `every path names a font that exists in the Flutter project`).

## Decisions this plan makes

- **Coalescing: one AlarmManager alarm per alert, collected at fire time.** The diff stays per id (which is what the roadmap's `armed/cancelled/kept` counts measure), moving one meeting never disturbs another alert's alarm, and Health can list individual alerts. When an alarm fires, `EngineReducer.fire` moves every scheduled alert with the same `coalesceGroup` (plan, snoozes and test alerts) to `presented` and cancels the siblings' own alarms, so each group rings once. A sibling whose receiver still runs finds its id gone and does nothing. Consequence for the diff: `PlanDiff` compares `id + fireAtUtcMs` per alert and never looks at groups.
- **Mixed-strength groups ring as an alarm.** If any alert in a fired group is `alarm`, the whole group goes to `RingingService` and is listed on the alarm screen; otherwise it is one heads-up notification.
- **An alarm that fires while another is ringing joins the current session** (the screen becomes the coalesced list) and the ring timeout restarts from the newest alert.
- **Coalesced heads-up notification** uses **Dismiss · Snooze all · Dismiss all**: the spec's "Stop" is relabelled "Dismiss" because a heads-up does not ring. It does the same thing as Stop (a single Dismiss of every listed alert).
- **Coalesced snooze options** are computed against the earliest start in the session; each alert's snooze time is computed from its own start; an option that is in the past for an alert becomes +1 min for that alert.
- **Countdown wording** rounds up before the start (30 s → "Starts in 1 min"), shows "Starting now" for the first 59 s after the start, then "Started N min ago".
- **No join link:** the primary 76 dp button is **Dismiss** (filled with the calendar colour) and **Snooze** is a full-width 64 dp outline button below it. With a link: **Join** (76 dp), then **Snooze | Dismiss** (64 dp each), then the text button "Dismiss all alerts for this event".
- **Back does nothing on the alarm screen.** Only buttons and the volume keys act; the ringing notification stays available.
- **The alarm screen follows the system dark/light setting.** The Flutter theme mode is persisted only in Plan 5 and is not readable from Kotlin.
- **Gradual volume** ramps the MediaPlayer gain from 10 % to 100 % over 30 s; it never changes the user's alarm-stream volume (Health reports a muted alarm stream).
- **Swiping a heads-up away** counts as a single Dismiss of the alerts it showed.
- **Test alerts** (`testAlarm`) live in their own `tests` list with `occurrenceKey = "test|<ms>"`, so `applyPlan` never cancels them, and they emit normal engine events. Title "Test alarm" / "Test heads-up", no join link, event starts 1 min after firing.
- **PlanStore persists two lists the roadmap does not name:** `presented` (fired alerts awaiting the user, needed to act on notification buttons after the process died) and `tests`.
- **Calendar name and organiser** ("Work Outlook", "Thandi M." in the mockups) are not in `EventSnapshot`, so the alarm screen does not show them.

Accepted after the whole-branch review (2026-10-06, user decisions; these amend the decisions above where they conflict):

- **Coalescing collects only alerts already due** (amends the first decision). When an alarm fires, `EngineReducer.fire` collects the scheduled alerts in the same `coalesceGroup` whose `fireAtUtcMs <= now`, and cancels only those siblings' alarms. A same-minute alert that comes due later fires on its own alarm and joins the ringing session, or the group's heads-up notification, when it fires. No alert rings before its own time.
- **PlanDiff re-arms when the strength changes** (amends the first decision's diff key). The diff compares `id + fireAtUtcMs + strength`, so a heads-up that becomes an alarm at the same time gets the alarm-clock AlarmManager call.
- **Overdue and orphaned alerts ring if their event has not ended.** An alert counts as overdue if its fire time has passed but it never fired (a late inexact alarm, a reboot that spans the fire time, a plan that arrives inside that window). An alert counts as orphaned if it is in `presented` after process death, a reboot or an app update. When the engine next runs (app start, boot, package replaced, time change, `applyPlan`), it treats both the same way. If the event has not ended, the alert is presented now; the screen then shows "Started N min ago". If the event has ended, the engine emits `missed` and posts a Missed notification. Overdue alerts are never dropped silently.
- **A ringing alarm takes transient audio focus** (`AUDIOFOCUS_GAIN_TRANSIENT`, `USAGE_ALARM`). Other audio pauses while the alarm rings and resumes when it stops.
- **A snooze whose occurrence moved is dropped.** If `applyPlan` brings an occurrence back with the same `occurrenceKey` but a different start, its pending snooze is cancelled. The re-planned alerts for the new time take over.
- **A heads-up group that gains members after it fired is one notification.** Each post lists every presented, non-ringing alert in the group (spec §6). A notification action removes the notification only when nothing in the group is left to show.
- **Kept as planned after review:** the inexact fallback stays `setAndAllowWhileIdle`; `drainEvents` keeps clear-on-read (roadmap §3; revisit in Plan 5); pruning runs only inside `applyPlan` (Plan 4 calls it).
- **Snooze events carry the snooze id** (`<id>:s`) as `alertId`. Plan 5's history and Dart's decision-8 single-Dismiss key must map `X:s` back to `X` (Plan 2 decision 8).
- **An alarm that fires into a group whose heads-up is showing absorbs it** (decided during Task 15). The heads-up alerts of that group join the ringing session. The heads-up notification is withdrawn, and the alarm screen and ringing notification list the whole group, the same as a mixed-strength group that fired together.
- **The ringing notification is colorized** (decided during Task 15). Android 16 force-groups an app's ungrouped notifications and marks them `FLAG_SILENT`, and SystemUI then suppresses their full-screen intent. A colorized foreground-service notification is never force-grouped, and mockup 6a already shows the ringing card filled.
- **Heads-up and Missed notifications use app-defined groups with posted summaries** (`GROUP_ALERT_CHILDREN`), so Android never force-groups and silences a new heads-up while another T-Minus notification is in the shade.
- **Any alert that joins a ringing session restarts the ring timeout** (decided during Task 15). A joining heads-up restarts it from its own `ringTimeoutSec`, the same as a joining alarm, so every alert in the session gets its full ring time before it counts as missed. The wake lock is extended to match.
- **A ringing alarm always has a working stop** (decided after Task 15). Sound plays only while there is a way to stop it. Every stop control silences the sound first and reconciles the engine state afterwards, whatever that state is: Stop, Dismiss, Dismiss all, Snooze, the volume keys and the alarm screen's buttons. The ring timeout stays as the backstop.
- **Opening T-Minus while an alarm rings goes to the alarm screen**, from the launcher icon or a recent-apps card. This gives a stop path even when notifications or full-screen intents are blocked.
- **With no visible stop control, the alarm still rings.** If notifications are blocked (for the app, or just the ringing channel) and full-screen intents are denied, it rings anyway. Opening the app (the alarm screen) stops it, and so does the ring timeout. Health flags the blocked permissions.
- **A swiped ringing notification comes straight back.** Android 14+ lets the user swipe an ongoing foreground-service notification away while unlocked. Its delete intent posts it again while anything is ringing.
- **Stop silences the whole session.** The ringing notification's Stop and the volume keys silence everything that is ringing, whatever ids they were posted with. A per-meeting Dismiss on the coalesced alarm screen removes just that meeting; the rest keep ringing. Ids that are stale (no longer in `presented`) are silenced too.
- **An alarm that was ringing at reboot fires again through AlarmManager.** Android 15+ forbids starting a `mediaPlayback` foreground service from the boot broadcasts. Boot recovery therefore schedules an immediate exact alarm, a few seconds out, so the alarm rings through the normal fire path.
- **Boot recovery fires 30 s after the boot.** For about 20 s after a boot broadcast, Android still refuses a `mediaPlayback` foreground service; a 3 s delay crashed in testing. An alarm that was ringing at reboot, or came due while the phone was off, therefore rings 30 s after the boot.
- **A crash never leaves sound playing.** A process-wide uncaught-exception handler stops the player and the vibration, then hands the crash on to the default handler.
- **A refused foreground start falls back to a heads-up.** If Android refuses the ringing service at `startForeground` (inside the service), the service catches the refusal, stops cleanly and posts the alert as a heads-up with its actions.
- **Health reports `ringingChannelEnabled`.** This is an additive field in the roadmap §3 `getHealth` row, so Plan 5 can warn when the "Ringing alarms" channel is off.
- **Plan 5 note: `AlarmEngine` delivers each event once, to the live stream or to `drainEvents`, whichever sees it first.** A second consumer of `events`, such as a UI refresh, takes events away from the history recorder. Plan 5 needs one consumer that records history and fans out to the UI (Task 15 found this in the debug panel).

```dart
enum AlertStrength { headsUp, alarm }

class AlertSpec {
  const AlertSpec(this.offsetMinutes, this.strength) : assert(offsetMinutes >= 0);
  final int offsetMinutes; // minutes before start
  final AlertStrength strength;

  @override
  bool operator ==(Object other) =>
      other is AlertSpec && other.offsetMinutes == offsetMinutes && other.strength == strength;
  @override
  int get hashCode => Object.hash(offsetMinutes, strength);
}

class SoundSettings {
  const SoundSettings({
    this.toneUri,
    this.vibrate = true,
    this.gradualVolume = true,
    this.ringTimeout = const Duration(minutes: 2),
  });
  final String? toneUri; // null = system default alarm tone
  final bool vibrate;
  final bool gradualVolume;
  final Duration ringTimeout;

  Map<String, Object?> toJson() => {
        'toneUri': toneUri,
        'vibrate': vibrate,
        'gradualVolume': gradualVolume,
        'ringTimeoutSec': ringTimeout.inSeconds,
      };

  factory SoundSettings.fromJson(Map<String, Object?> j) => SoundSettings(
        toneUri: j['toneUri'] as String?,
        vibrate: j['vibrate'] as bool,
        gradualVolume: j['gradualVolume'] as bool,
        ringTimeout: Duration(seconds: j['ringTimeoutSec'] as int),
      );

  @override
  bool operator ==(Object other) =>
      other is SoundSettings &&
      other.toneUri == toneUri &&
      other.vibrate == vibrate &&
      other.gradualVolume == gradualVolume &&
      other.ringTimeout == ringTimeout;
```

```dart
import 'alert.dart';

/// What the native engine needs to ring and show an alert without Flutter.
class EventSnapshot {
  const EventSnapshot({
    required this.title,
    required this.startUtc,
    required this.endUtc,
    this.location,
    this.joinUrl,
    required this.color,
  });
  final String title;
  final DateTime startUtc;
  final DateTime endUtc;
  final String? location;
  final String? joinUrl;
  final int color; // ARGB, e.g. 0xFF6AA0F5

  Map<String, Object?> toJson() => {
        'title': title,
        'startUtcMs': startUtc.millisecondsSinceEpoch,
        'endUtcMs': endUtc.millisecondsSinceEpoch,
        'location': location,
        'joinUrl': joinUrl,
        'color': color,
      };

  factory EventSnapshot.fromJson(Map<String, Object?> j) => EventSnapshot(
        title: j['title'] as String,
        startUtc: DateTime.fromMillisecondsSinceEpoch(j['startUtcMs'] as int, isUtc: true),
        endUtc: DateTime.fromMillisecondsSinceEpoch(j['endUtcMs'] as int, isUtc: true),
        location: j['location'] as String?,
        joinUrl: j['joinUrl'] as String?,
        color: j['color'] as int,
      );
}

class PlannedAlert {
  const PlannedAlert({
    required this.id,
    required this.occurrenceKey,
    required this.fireAtUtc,
    required this.offsetMinutes,
    required this.strength,
    required this.sound,
    required this.event,
    required this.coalesceGroup,
  });

  final String id;            // PlannedAlert.idFor(occurrenceKey, offsetMinutes)
  final String occurrenceKey;
  final DateTime fireAtUtc;   // event.startUtc - offsetMinutes
  final int offsetMinutes;
  final AlertStrength strength;
  final SoundSettings sound;
  final EventSnapshot event;
  final String coalesceGroup; // PlannedAlert.groupFor(fireAtUtc)

  /// Stable id: FNV-1a 64-bit of "$occurrenceKey|$offsetMinutes", 16 lowercase hex chars.
  static String idFor(String occurrenceKey, int offsetMinutes) {
    var hash = 0xcbf29ce484222325; // 64-bit VM ints wrap on overflow
    for (final unit in '$occurrenceKey|$offsetMinutes'.codeUnits) {
      hash ^= unit;
      hash *= 0x100000001b3;
    }
    // Print as unsigned: toRadixString on a negative int would emit a '-'.
    String hex32(int v) => (v & 0xFFFFFFFF).toRadixString(16).padLeft(8, '0');
    return hex32(hash >> 32) + hex32(hash);
  }

  /// Alerts in the same UTC minute share a group: "yyyy-MM-ddTHH:mmZ".
  static String groupFor(DateTime fireAtUtc) {
    final t = fireAtUtc.toUtc();
    String two(int v) => v.toString().padLeft(2, '0');
    return '${t.year}-${two(t.month)}-${two(t.day)}T${two(t.hour)}:${two(t.minute)}Z';
  }

  Map<String, Object?> toJson() => {
        'id': id,
        'occurrenceKey': occurrenceKey,
        'fireAtUtcMs': fireAtUtc.millisecondsSinceEpoch,
        'offsetMinutes': offsetMinutes,
        'strength': strength.name, // "headsUp" | "alarm"
        'sound': sound.toJson(),
        'event': event.toJson(),
        'coalesceGroup': coalesceGroup,
      };

  factory PlannedAlert.fromJson(Map<String, Object?> j) => PlannedAlert(
```

```kotlin
package io.github.fifothehein.tminus.engine

/** One minute in milliseconds. */
const val MINUTE_MS: Long = 60_000L

/** The four smart-snooze choices (spec §6). Pure Kotlin, so it runs in plain JUnit. */
enum class SnoozeOption(val label: String) {
    PLUS_1_MIN("+1 min"),
    PLUS_5_MIN("+5 min"),
    ONE_MIN_BEFORE_START("1 min before start"),
    AT_START("At start");

    /** The absolute UTC time this option snoozes until. */
    fun untilUtcMs(nowUtcMs: Long, startUtcMs: Long): Long = when (this) {
        PLUS_1_MIN -> nowUtcMs + MINUTE_MS
        PLUS_5_MIN -> nowUtcMs + 5 * MINUTE_MS
        ONE_MIN_BEFORE_START -> startUtcMs - MINUTE_MS
        AT_START -> startUtcMs
    }
}

object SnoozeOptions {
    /** Options whose time is still in the future, in display order (spec §6: past options are hidden). */
    fun visible(nowUtcMs: Long, startUtcMs: Long): List<SnoozeOption> =
        SnoozeOption.entries.filter { it.untilUtcMs(nowUtcMs, startUtcMs) > nowUtcMs }

    /**
     * The option behind a notification's single Snooze action (roadmap §5.1): +5 min;
     * At start if the meeting starts sooner than that; +1 min once it has started.
     */
    fun notificationDefault(nowUtcMs: Long, startUtcMs: Long): SnoozeOption = when {
        startUtcMs <= nowUtcMs -> SnoozeOption.PLUS_1_MIN
        startUtcMs < nowUtcMs + 5 * MINUTE_MS -> SnoozeOption.AT_START
        else -> SnoozeOption.PLUS_5_MIN
    }

    /** [option]'s time, or +1 min when that time is not in the future. */
    fun untilOrNextMinute(option: SnoozeOption, nowUtcMs: Long, startUtcMs: Long): Long {
        val until = option.untilUtcMs(nowUtcMs, startUtcMs)
        return if (until > nowUtcMs) until else nowUtcMs + MINUTE_MS
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

/** How far an event's start is from now, worded as the alarm screen and notifications show it. */
sealed interface Countdown {
    data class StartsIn(val minutes: Long) : Countdown
    data object StartingNow : Countdown
    data class StartedAgo(val minutes: Long) : Countdown

    /** "Starts in 1 min" · "Starting now" · "Started 2 min ago". */
    fun sentence(): String = when (this) {
        is StartsIn -> "Starts in $minutes min"
        StartingNow -> "Starting now"
        is StartedAgo -> "Started $minutes min ago"
    }

    /** Heads-up form: "In 10 min" · "Now" · "Started 2 min ago". */
    fun short(): String = when (this) {
        is StartsIn -> "In $minutes min"
        StartingNow -> "Now"
        is StartedAgo -> "Started $minutes min ago"
    }

    companion object {
        /** Rounds up before the start (30 s → 1 min) and down after it. */
        fun of(nowUtcMs: Long, startUtcMs: Long): Countdown {
            val delta = startUtcMs - nowUtcMs
            return when {
                delta > 0 -> StartsIn((delta + MINUTE_MS - 1) / MINUTE_MS)
                delta > -MINUTE_MS -> StartingNow
                else -> StartedAgo(-delta / MINUTE_MS)
            }
        }
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import java.time.Instant
import java.time.ZoneOffset
import java.time.format.DateTimeFormatter

/** Alert strength; [wire] is the Dart `AlertStrength.name`. */
enum class Strength(val wire: String) {
    HEADS_UP("headsUp"),
    ALARM("alarm");

    companion object {
        fun fromWire(wire: String): Strength =
            entries.firstOrNull { it.wire == wire } ?: throw IllegalArgumentException("Unknown strength: $wire")
    }
}

/** Mirrors Dart `SoundSettings`. */
data class Sound(
    val toneUri: String?,
    val vibrate: Boolean,
    val gradualVolume: Boolean,
    val ringTimeoutSec: Int,
) {
    companion object {
        val DEFAULT = Sound(toneUri = null, vibrate = true, gradualVolume = true, ringTimeoutSec = 120)
    }
}

/** Mirrors Dart `EventSnapshot`. Times are UTC epoch milliseconds; [color] is ARGB. */
data class EventSnapshot(
    val title: String,
    val startUtcMs: Long,
    val endUtcMs: Long,
    val location: String?,
    val joinUrl: String?,
    val color: Long,
)

/** Mirrors Dart `PlannedAlert`. Kotlin treats [id] as an opaque string (roadmap §3). */
data class PlannedAlert(
    val id: String,
    val occurrenceKey: String,
    val fireAtUtcMs: Long,
    val offsetMinutes: Int,
    val strength: Strength,
    val sound: Sound,
    val event: EventSnapshot,
    val coalesceGroup: String,
) {
    /** True for alerts created by `testAlarm`. */
    val isTest: Boolean get() = occurrenceKey.startsWith(EngineState.TEST_KEY_PREFIX)
}

/** Dismiss all / Join of one occurrence at one start time (roadmap §3). */
data class Ack(val occurrenceKey: String, val startUtcMs: Long)

/** A single Dismiss / Stop of one alert at one fire time (roadmap §3). */
data class Dismissal(val alertId: String, val fireAtUtcMs: Long)

/**
 * Everything PlanStore persists.
 * - [plan]: future alerts from the last applyPlan; each has an AlarmManager alarm.
 * - [snoozes]: Kotlin-created snoozes (`<id>:s`) of plan alerts.
 * - [tests]: alerts from testAlarm and their snoozes; applyPlan never touches them.
 * - [presented]: alerts that fired and wait for the user (ringing, or a heads-up on screen).
 */
data class EngineState(
    val plan: List<PlannedAlert> = emptyList(),
    val snoozes: List<PlannedAlert> = emptyList(),
    val tests: List<PlannedAlert> = emptyList(),
    val presented: List<PlannedAlert> = emptyList(),
    val acks: List<Ack> = emptyList(),
    val dismissed: List<Dismissal> = emptyList(),
) {
    /** Every alert that has an AlarmManager alarm. */
    val scheduled: List<PlannedAlert> get() = plan + snoozes + tests

    fun isAcked(occurrenceKey: String, startUtcMs: Long): Boolean =
        acks.any { it.occurrenceKey == occurrenceKey && it.startUtcMs == startUtcMs }

    fun isDismissed(alertId: String, fireAtUtcMs: Long): Boolean =
        dismissed.any { it.alertId == alertId && it.fireAtUtcMs == fireAtUtcMs }

    /** This state with [ids] removed from plan, snoozes and tests. */
    fun withoutScheduled(ids: Set<String>): EngineState = copy(
        plan = plan.filterNot { it.id in ids },
        snoozes = snoozes.filterNot { it.id in ids },
        tests = tests.filterNot { it.id in ids },
    )

    companion object {
        val EMPTY = EngineState()
        const val TEST_KEY_PREFIX = "test|"
    }
}

/** Kotlin twin of Dart `PlannedAlert.groupFor` ("yyyy-MM-ddTHH:mmZ", UTC), for snoozes and test alerts. */
object CoalesceGroups {
    private val format = DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm'Z'").withZone(ZoneOffset.UTC)

    fun groupFor(fireAtUtcMs: Long): String = format.format(Instant.ofEpochMilli(fireAtUtcMs))
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import org.json.JSONArray
import org.json.JSONObject

/** org.json mapping (roadmap §5.4). Alert keys match Dart `PlannedAlert.toJson` exactly. */
object EngineJson {
    const val PLAN_VERSION = 1
    private const val STATE_VERSION = 1

    /** Parses the applyPlan argument `{"version": 1, "alerts": [...]}` as the Flutter codec delivers it. */
    fun parsePlan(args: Map<*, *>): List<PlannedAlert> {
        val o = JSONObject(args)
        val version = o.getInt("version")
        require(version == PLAN_VERSION) { "Unsupported plan version $version" }
        return o.getJSONArray("alerts").objects().map(::alertFromJson)
    }

    fun alertToJson(a: PlannedAlert): JSONObject = JSONObject()
        .put("id", a.id)
        .put("occurrenceKey", a.occurrenceKey)
        .put("fireAtUtcMs", a.fireAtUtcMs)
        .put("offsetMinutes", a.offsetMinutes)
        .put("strength", a.strength.wire)
        .put(
            "sound",
            JSONObject()
                .put("toneUri", a.sound.toneUri ?: JSONObject.NULL)
                .put("vibrate", a.sound.vibrate)
                .put("gradualVolume", a.sound.gradualVolume)
                .put("ringTimeoutSec", a.sound.ringTimeoutSec),
        )
        .put(
            "event",
            JSONObject()
                .put("title", a.event.title)
                .put("startUtcMs", a.event.startUtcMs)
                .put("endUtcMs", a.event.endUtcMs)
                .put("location", a.event.location ?: JSONObject.NULL)
                .put("joinUrl", a.event.joinUrl ?: JSONObject.NULL)
                .put("color", a.event.color),
        )
        .put("coalesceGroup", a.coalesceGroup)

    fun alertFromJson(o: JSONObject): PlannedAlert {
        val s = o.getJSONObject("sound")
        val e = o.getJSONObject("event")
        return PlannedAlert(
            id = o.getString("id"),
            occurrenceKey = o.getString("occurrenceKey"),
            fireAtUtcMs = o.getLong("fireAtUtcMs"),
            offsetMinutes = o.getInt("offsetMinutes"),
            strength = Strength.fromWire(o.getString("strength")),
            sound = Sound(
                toneUri = s.stringOrNull("toneUri"),
                vibrate = s.getBoolean("vibrate"),
                gradualVolume = s.getBoolean("gradualVolume"),
                ringTimeoutSec = s.getInt("ringTimeoutSec"),
            ),
            event = EventSnapshot(
                title = e.getString("title"),
                startUtcMs = e.getLong("startUtcMs"),
                endUtcMs = e.getLong("endUtcMs"),
                location = e.stringOrNull("location"),
                joinUrl = e.stringOrNull("joinUrl"),
                color = e.getLong("color"),
            ),
            coalesceGroup = o.getString("coalesceGroup"),
        )
    }

    fun stateToJson(state: EngineState): JSONObject = JSONObject()
        .put("version", STATE_VERSION)
        .put("plan", alerts(state.plan))
        .put("snoozes", alerts(state.snoozes))
        .put("tests", alerts(state.tests))
        .put("presented", alerts(state.presented))
        .put(
            "acks",
            JSONArray(state.acks.map { JSONObject().put("occurrenceKey", it.occurrenceKey).put("startUtcMs", it.startUtcMs) }),
        )
        .put(
            "dismissed",
            JSONArray(state.dismissed.map { JSONObject().put("alertId", it.alertId).put("fireAtUtcMs", it.fireAtUtcMs) }),
        )

    fun stateFromJson(o: JSONObject): EngineState {
        val version = o.getInt("version")
        require(version == STATE_VERSION) { "Unsupported state version $version" }
        return EngineState(
            plan = o.getJSONArray("plan").objects().map(::alertFromJson),
            snoozes = o.getJSONArray("snoozes").objects().map(::alertFromJson),
            tests = o.getJSONArray("tests").objects().map(::alertFromJson),
            presented = o.getJSONArray("presented").objects().map(::alertFromJson),
            acks = o.getJSONArray("acks").objects().map { Ack(it.getString("occurrenceKey"), it.getLong("startUtcMs")) },
            dismissed = o.getJSONArray("dismissed").objects().map { Dismissal(it.getString("alertId"), it.getLong("fireAtUtcMs")) },
        )
    }

    /** A plain map the Flutter codec can send; JSON nulls become Kotlin nulls. */
    fun toMap(o: JSONObject): Map<String, Any?> =
        o.keys().asSequence().associateWith { key -> unwrap(o.get(key)) }

    private fun unwrap(v: Any?): Any? = when (v) {
        JSONObject.NULL -> null
        is JSONObject -> toMap(v)
        is JSONArray -> (0 until v.length()).map { unwrap(v.get(it)) }
        else -> v
    }

    private fun alerts(list: List<PlannedAlert>) = JSONArray(list.map(::alertToJson))

    private fun JSONArray.objects(): List<JSONObject> = (0 until length()).map { getJSONObject(it) }

    private fun JSONObject.stringOrNull(key: String): String? = if (isNull(key)) null else getString(key)
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context
import android.util.Log
import org.json.JSONObject
import java.io.File
import java.io.FileOutputStream
import java.nio.file.Files
import java.nio.file.StandardCopyOption

/**
 * The engine's state as one JSON file in device-protected storage, so alarms can be re-armed
 * after a reboot before the user unlocks (spec §7). Writes are atomic: temp file, fsync, rename.
 */
class PlanStore(context: Context) {
    private val dir = File(context.createDeviceProtectedStorageContext().filesDir, DIR_NAME)
    internal val stateFile = File(dir, FILE_NAME)
    internal val tempFile = File(dir, "$FILE_NAME.tmp")

    fun read(): EngineState = synchronized(LOCK) { readLocked() }

    fun write(state: EngineState) = synchronized(LOCK) { writeLocked(state) }

    /** Read-modify-write under the store lock. Writes only when the state changed. */
    fun <T> update(block: (EngineState) -> Pair<EngineState, T>): T = synchronized(LOCK) {
        val current = readLocked()
        val (next, result) = block(current)
        if (next != current) writeLocked(next)
        result
    }

    fun clear() = synchronized(LOCK) {
        stateFile.delete()
        tempFile.delete()
        Unit
    }

    private fun readLocked(): EngineState {
        if (!stateFile.exists()) return EngineState.EMPTY
        return try {
            EngineJson.stateFromJson(JSONObject(stateFile.readText()))
        } catch (e: Exception) {
            Log.e(TAG, "Engine state unreadable; starting from an empty plan", e)
            runCatching { stateFile.copyTo(File(dir, "$FILE_NAME.corrupt"), overwrite = true) }
            EngineState.EMPTY
        }
    }

    private fun writeLocked(state: EngineState) {
        dir.mkdirs()
        FileOutputStream(tempFile).use { out ->
            out.write(EngineJson.stateToJson(state).toString().toByteArray(Charsets.UTF_8))
            out.fd.sync()
        }
        // rename(2) on Android; MoveFileEx(REPLACE_EXISTING) on the Windows test host.
        Files.move(tempFile.toPath(), stateFile.toPath(), StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE)
    }

    companion object {
        const val DIR_NAME = "engine"
        const val FILE_NAME = "state.json"
        private const val TAG = "TMinusEngine"
        private val LOCK = Any()
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

/** The outcome of one engine state change. */
data class Transition(
    val state: EngineState,
    /** The alerts the action applied to (fired, snoozed, dismissed …). */
    val affected: List<PlannedAlert> = emptyList(),
    /** Alerts that left [EngineState.presented]: their notification or screen must go. */
    val withdrawn: List<PlannedAlert> = emptyList(),
    /** Alerts that need an AlarmManager alarm. */
    val toArm: List<PlannedAlert> = emptyList(),
    /** Alerts whose AlarmManager alarm must be cancelled. */
    val toCancel: List<PlannedAlert> = emptyList(),
)

/** Pure state changes for firing and user actions. No Android types. */
object EngineReducer {
    const val SNOOZE_SUFFIX = ":s"
    const val RETENTION_MS: Long = 24 * 60 * MINUTE_MS
    private const val PRESENTED_GRACE_MS: Long = 60 * MINUTE_MS

    private val displayOrder = compareBy<PlannedAlert>({ it.event.startUtcMs }, { it.event.title }, { it.id })

    /** Collects every scheduled alert in the fired alert's coalesce group (one alarm per alert, collected at fire). */
    fun fire(state: EngineState, alertId: String): Transition {
        val hit = state.scheduled.firstOrNull { it.id == alertId } ?: return Transition(state)
        val group = state.scheduled.filter { it.coalesceGroup == hit.coalesceGroup }.sortedWith(displayOrder)
        val ids = group.map { it.id }.toSet()
        return Transition(
            state = state.withoutScheduled(ids).copy(presented = state.presented.filterNot { it.id in ids } + group),
            affected = group,
            toCancel = group.filter { it.id != alertId },
        )
    }

    fun snoozeIdFor(alertId: String): String = alertId.removeSuffix(SNOOZE_SUFFIX) + SNOOZE_SUFFIX

    fun snooze(state: EngineState, alertIds: Collection<String>, untilFor: (PlannedAlert) -> Long): Transition {
        val targets = state.presented.filter { it.id in alertIds }
        if (targets.isEmpty()) return Transition(state)
        val created = targets.map { a ->
            val until = untilFor(a)
            a.copy(id = snoozeIdFor(a.id), fireAtUtcMs = until, coalesceGroup = CoalesceGroups.groupFor(until))
        }
        val createdIds = created.map { it.id }.toSet()
        val targetIds = targets.map { it.id }.toSet()
        val (testSnoozes, planSnoozes) = created.partition { it.isTest }
        return Transition(
            state = state.copy(
                presented = state.presented.filterNot { it.id in targetIds },
                snoozes = state.snoozes.filterNot { it.id in createdIds } + planSnoozes,
                tests = state.tests.filterNot { it.id in createdIds } + testSnoozes,
            ),
            affected = targets,
            withdrawn = targets,
            toArm = created,
        )
    }

    fun dismiss(state: EngineState, alertIds: Collection<String>): Transition {
        val targets = state.presented.filter { it.id in alertIds }
        if (targets.isEmpty()) return Transition(state)
        val ids = targets.map { it.id }.toSet()
        return Transition(
            state = state.copy(
                presented = state.presented.filterNot { it.id in ids },
                dismissed = (state.dismissed + targets.map { Dismissal(it.id, it.fireAtUtcMs) }).distinct(),
            ),
            affected = targets,
            withdrawn = targets,
        )
    }

    /** Dismiss all / Join: acks each target's occurrence at its start and drops everything else for it. */
    fun acknowledge(state: EngineState, alertIds: Collection<String>): Transition {
        val targets = state.presented.filter { it.id in alertIds }
        if (targets.isEmpty()) return Transition(state)
        val acks = targets.map { Ack(it.occurrenceKey, it.event.startUtcMs) }.distinct()
        fun covered(a: PlannedAlert) = acks.any { it.occurrenceKey == a.occurrenceKey && it.startUtcMs == a.event.startUtcMs }
        val cancelled = state.scheduled.filter(::covered)
        val withdrawn = state.presented.filter(::covered)
        return Transition(
            state = state.withoutScheduled(cancelled.map { it.id }.toSet()).copy(
                presented = state.presented.filterNot(::covered),
                acks = (state.acks + acks).distinct(),
            ),
            affected = targets,
            withdrawn = withdrawn,
            toCancel = cancelled,
        )
    }

    fun missed(state: EngineState, alertIds: Collection<String>): Transition {
        val targets = state.presented.filter { it.id in alertIds }
        if (targets.isEmpty()) return Transition(state)
        val ids = targets.map { it.id }.toSet()
        return Transition(
            state = state.copy(presented = state.presented.filterNot { it.id in ids }),
            affected = targets,
            withdrawn = targets,
        )
    }

    fun addTest(state: EngineState, alert: PlannedAlert): Transition = Transition(
        state = state.copy(tests = state.tests.filterNot { it.id == alert.id } + alert),
        affected = listOf(alert),
        toArm = listOf(alert),
    )

    /** Acks and dismissals live 24 h after their time (roadmap §3); presented alerts an hour after the event ends. */
    fun prune(state: EngineState, nowUtcMs: Long): EngineState = state.copy(
        acks = state.acks.filter { it.startUtcMs + RETENTION_MS >= nowUtcMs },
        dismissed = state.dismissed.filter { it.fireAtUtcMs + RETENTION_MS >= nowUtcMs },
        presented = state.presented.filter { it.event.endUtcMs + PRESENTED_GRACE_MS >= nowUtcMs },
    )
}
```

```kotlin
package io.github.fifothehein.tminus.engine

data class PlanDiffResult(
    val state: EngineState,
    val toArm: List<PlannedAlert>,
    val toCancel: List<PlannedAlert>,
    val kept: List<PlannedAlert>,
)

/** The applyPlan diff (spec §7, roadmap §3 engine rules). Pure: AlarmScheduler carries out the result. */
object PlanDiff {
    fun apply(old: EngineState, incoming: List<PlannedAlert>, nowUtcMs: Long): PlanDiffResult {
        val base = EngineReducer.prune(old, nowUtcMs)
        val wanted = incoming.distinctBy { it.id }.filter { a ->
            a.fireAtUtcMs > nowUtcMs &&
                !base.isAcked(a.occurrenceKey, a.event.startUtcMs) &&
                !base.isDismissed(a.id, a.fireAtUtcMs) &&
                base.presented.none { it.id == a.id && it.fireAtUtcMs == a.fireAtUtcMs }
        }
        fun sameAlarm(a: PlannedAlert, b: PlannedAlert) = a.id == b.id && a.fireAtUtcMs == b.fireAtUtcMs
        val armedBefore = base.plan.filter { it.fireAtUtcMs > nowUtcMs }
        val kept = wanted.filter { w -> armedBefore.any { sameAlarm(it, w) } }
        val newOrMoved = wanted.filter { w -> armedBefore.none { sameAlarm(it, w) } }
        val gone = armedBefore.filter { o -> wanted.none { sameAlarm(it, o) } }

        val plannedKeys = incoming.map { it.occurrenceKey }.toSet()
        val (keepSnoozes, dropSnoozes) = base.snoozes.partition {
            it.fireAtUtcMs > nowUtcMs && it.occurrenceKey in plannedKeys && !base.isAcked(it.occurrenceKey, it.event.startUtcMs)
        }
        return PlanDiffResult(
            state = base.copy(plan = wanted, snoozes = keepSnoozes),
            toArm = newOrMoved,
            toCancel = gone + dropSnoozes,
            kept = kept,
        )
    }
}
```

```kotlin
import android.app.AlarmManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.os.Build
import android.util.Log
import io.github.fifothehein.tminus.MainActivity

data class ApplyResult(val armed: Int, val cancelled: Int, val kept: Int) {
    fun toMap(): Map<String, Int> = mapOf("armed" to armed, "cancelled" to cancelled, "kept" to kept)
}

/**
 * Owns every AlarmManager call. One alarm per alert, keyed by alert id (PendingIntent request
 * code = id.hashCode(), roadmap §3); coalescing happens at fire time in EngineReducer.fire.
 */
class AlarmScheduler(
    context: Context,
    private val store: PlanStore = PlanStore(context),
    private val clock: () -> Long = System::currentTimeMillis,
) {
    private val appContext: Context = context.applicationContext
    private val alarmManager: AlarmManager = appContext.getSystemService(AlarmManager::class.java)

    fun applyPlan(incoming: List<PlannedAlert>): ApplyResult {
        val now = clock()
        val diff = store.update { old -> PlanDiff.apply(old, incoming, now).let { it.state to it } }
        diff.toCancel.forEach { cancel(it.id) }
        diff.toArm.forEach(::arm)
        val vanished = diff.kept.filterNot(::isArmed) // e.g. after a force stop
        vanished.forEach(::arm)
        return ApplyResult(
            armed = diff.toArm.size + vanished.size,
            cancelled = diff.toCancel.size,
            kept = diff.kept.size - vanished.size,
        )
    }

    /** Re-arm triggers (spec §7) and app start: arm every future alert, drop past ones. */
    fun rearmAll(): Int {
        val now = clock()
        val (future, past) = store.update { s ->
            val (f, p) = s.scheduled.partition { it.fireAtUtcMs > now }
            s.withoutScheduled(p.map { it.id }.toSet()) to (f to p)
        }
        past.forEach { cancel(it.id) }
        future.forEach(::arm)
        Log.i(TAG, "Re-armed ${future.size} alerts, dropped ${past.size} past ones")
        return future.size
    }

    fun arm(alert: PlannedAlert) {
        val operation = operation(alert.id, PendingIntent.FLAG_UPDATE_CURRENT)!!
        val at = alert.fireAtUtcMs
        try {
            when {
                !canScheduleExactAlarms() -> alarmManager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at, operation)
                alert.strength == Strength.ALARM ->
                    alarmManager.setAlarmClock(AlarmManager.AlarmClockInfo(at, showIntent()), operation)
                else -> alarmManager.setExactAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at, operation)
            }
        } catch (e: SecurityException) {
            Log.w(TAG, "Exact alarm refused for ${alert.id}; using an inexact alarm", e)
            alarmManager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at, operation)
        }
    }

    fun cancel(alertId: String) {
        val operation = operation(alertId, PendingIntent.FLAG_NO_CREATE) ?: return
        alarmManager.cancel(operation)
        operation.cancel()
    }

    fun isArmed(alert: PlannedAlert): Boolean = operation(alert.id, PendingIntent.FLAG_NO_CREATE) != null

    fun upcoming(limit: Int = 5): List<PlannedAlert> {
        val now = clock()
        return store.read().scheduled.filter { it.fireAtUtcMs > now }.sortedBy { it.fireAtUtcMs }.take(limit)
    }

    fun canScheduleExactAlarms(): Boolean =
        Build.VERSION.SDK_INT < Build.VERSION_CODES.S || alarmManager.canScheduleExactAlarms()

    private fun operation(alertId: String, flags: Int): PendingIntent? = PendingIntent.getBroadcast(
        appContext,
        alertId.hashCode(),
        AlarmReceiver.fireIntent(appContext, alertId),
        flags or PendingIntent.FLAG_IMMUTABLE,
    )

    /** setAlarmClock's show intent opens the app (the Agenda, once Plan 5 exists). */
    private fun showIntent(): PendingIntent = PendingIntent.getActivity(
        appContext,
        SHOW_REQUEST_CODE,
        Intent(appContext, MainActivity::class.java).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_SINGLE_TOP),
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
    )

    companion object {
        private const val TAG = "TMinusEngine"
        private const val SHOW_REQUEST_CODE = 0x5101
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context
import android.os.Handler
import android.os.Looper
import android.util.Log
import org.json.JSONObject
import java.io.File

/**
 * Engine events waiting for Dart, one JSON object per line, in device-protected storage.
 * Every event is appended, whether or not it was also streamed live (roadmap §3).
 */
class EventQueue(context: Context) {
    internal val file = File(File(context.createDeviceProtectedStorageContext().filesDir, PlanStore.DIR_NAME), FILE_NAME)

    fun append(event: EngineEvent) = synchronized(LOCK) {
        file.parentFile!!.mkdirs()
        val line = EngineJson.eventToJson(event).toString()
        val existing = readLinesLocked()
        if (existing.size >= MAX_EVENTS) {
            file.writeText((existing.takeLast(MAX_EVENTS - 1) + line).joinToString(separator = "\n", postfix = "\n"))
        } else {
            file.appendText(line + "\n")
        }
    }

    fun peek(): List<EngineEvent> = synchronized(LOCK) { parse(readLinesLocked()) }

    /** Returns every queued event and empties the queue. */
    fun drain(): List<EngineEvent> = synchronized(LOCK) {
        val events = parse(readLinesLocked())
        file.delete()
        events
    }

    private fun readLinesLocked(): List<String> =
        if (file.exists()) file.readLines().filter { it.isNotBlank() } else emptyList()

    private fun parse(lines: List<String>): List<EngineEvent> = lines.mapNotNull { line ->
        try {
            EngineJson.eventFromJson(JSONObject(line))
        } catch (e: Exception) {
            Log.w(TAG, "Skipping an unreadable queued event", e)
            null
        }
    }

    companion object {
        const val FILE_NAME = "events.jsonl"
        /** If Dart never drains, keep the newest 500 rather than grow forever. */
        const val MAX_EVENTS = 500
        private const val TAG = "TMinusEngine"
        private val LOCK = Any()
    }
}

/** Queues every engine event and streams it to Dart while `alarm_engine/events` has a listener. */
object EngineEvents {
    /** Set by AlarmEngineChannel.onListen, cleared by onCancel. */
    @Volatile
    var listener: ((Map<String, Any?>) -> Unit)? = null

    private val mainHandler by lazy { Handler(Looper.getMainLooper()) }

    fun emit(context: Context, event: EngineEvent) {
        EventQueue(context).append(event)
        val current = listener ?: return
        val map = event.toMap()
        mainHandler.post { current(map) }
    }
}
```

```kotlin
/** Native side of the `alarm_engine` MethodChannel and the `alarm_engine/events` EventChannel (roadmap §3). */
class AlarmEngineChannel internal constructor(
    context: Context,
    private val store: PlanStore = PlanStore(context),
    private val scheduler: AlarmScheduler = AlarmScheduler(context, store),
    private val clock: () -> Long = System::currentTimeMillis,
) : MethodChannel.MethodCallHandler, EventChannel.StreamHandler {
    private val appContext: Context = context.applicationContext

    override fun onMethodCall(call: MethodCall, result: MethodChannel.Result) {
        try {
            when (call.method) {
                "applyPlan" -> result.success(scheduler.applyPlan(EngineJson.parsePlan(call.mapArgs())).toMap())
                "getHealth" -> result.success(health())
                "testAlarm" -> {
                    testAlarm(call.mapArgs())
                    result.success(null)
                }
                "openPermissionSettings" -> {
                    openPermissionSettings(call.mapArgs())
                    result.success(null)
                }
                "drainEvents" -> result.success(EventQueue(appContext).drain().map { it.toMap() })
                else -> result.notImplemented()
            }
        } catch (e: IllegalArgumentException) {
            result.error("bad_args", e.message, null)
        } catch (e: JSONException) {
            result.error("bad_args", e.message, null)
        } catch (e: ClassCastException) {
            result.error("bad_args", e.message, null)
        } catch (e: Exception) {
            Log.e(TAG, "alarm_engine.${call.method} failed", e)
            result.error("engine_error", e.message, null)
        }
    }

    override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
        EngineEvents.listener = { events.success(it) }
    }

    override fun onCancel(arguments: Any?) {
        EngineEvents.listener = null
    }

    private fun MethodCall.mapArgs(): Map<*, *> =
        arguments as? Map<*, *> ?: throw IllegalArgumentException("$method expects a map argument")

    private fun health(): Map<String, Any?> {
        val notifications = appContext.getSystemService(NotificationManager::class.java)
        val power = appContext.getSystemService(PowerManager::class.java)
        val audio = appContext.getSystemService(AudioManager::class.java)
        return mapOf(
            "notificationsEnabled" to NotificationManagerCompat.from(appContext).areNotificationsEnabled(),
            "canUseFullScreenIntent" to (Build.VERSION.SDK_INT < 34 || notifications.canUseFullScreenIntent()),
            "canScheduleExactAlarms" to scheduler.canScheduleExactAlarms(),
            "ignoringBatteryOptimizations" to power.isIgnoringBatteryOptimizations(appContext.packageName),
            "alarmStreamMuted" to (audio.getStreamVolume(AudioManager.STREAM_ALARM) == 0),
            "upcoming" to scheduler.upcoming(5).map {
                mapOf("id" to it.id, "fireAtUtcMs" to it.fireAtUtcMs, "strength" to it.strength.wire, "title" to it.event.title)
            },
        )
    }

    private fun testAlarm(args: Map<*, *>) {
        val strength = Strength.fromWire(args["strength"] as? String ?: throw IllegalArgumentException("strength missing"))
        val delaySec = (args["delaySec"] as? Number)?.toLong() ?: throw IllegalArgumentException("delaySec missing")
        require(delaySec >= 0) { "delaySec must not be negative" }
        val now = clock()
        val fireAt = now + delaySec * 1_000
        val start = fireAt + MINUTE_MS
        val alert = PlannedAlert(
            id = "test-$now",
            occurrenceKey = "${EngineState.TEST_KEY_PREFIX}$now",
            fireAtUtcMs = fireAt,
            offsetMinutes = 1,
            strength = strength,
            sound = Sound.DEFAULT,
            event = EventSnapshot(
                title = if (strength == Strength.ALARM) "Test alarm" else "Test heads-up",
                startUtcMs = start,
                endUtcMs = start + 30 * MINUTE_MS,
                location = null,
                joinUrl = null,
                color = TEST_COLOR,
            ),
            coalesceGroup = CoalesceGroups.groupFor(fireAt),
        )
        val t = store.update { s -> EngineReducer.addTest(s, alert).let { it.state to it } }
        t.toArm.forEach(scheduler::arm)
    }

    private fun openPermissionSettings(args: Map<*, *>) {
        val pkg = appContext.packageName
        val packageUri = Uri.parse("package:$pkg")
        val intent = when (val kind = args["kind"] as? String) {
            "notifications" -> notificationSettings(pkg)
            "fullScreenIntent" ->
                if (Build.VERSION.SDK_INT >= 34) Intent(Settings.ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT, packageUri)
                else notificationSettings(pkg)
            "exactAlarm" ->
                if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) Intent(Settings.ACTION_REQUEST_SCHEDULE_EXACT_ALARM, packageUri)
                else appDetails(packageUri)
            // Not ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: that needs a permission Play restricts (spec §7).
            "batteryOptimization" -> Intent(Settings.ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS)
            "alarmVolume" -> Intent(Settings.ACTION_SOUND_SETTINGS)
            else -> throw IllegalArgumentException("Unknown permission kind: $kind")
        }
        try {
            appContext.startActivity(intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
        } catch (e: ActivityNotFoundException) {
            appContext.startActivity(appDetails(packageUri).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
        }
    }

    private fun notificationSettings(pkg: String) =
        Intent(Settings.ACTION_APP_NOTIFICATION_SETTINGS).putExtra(Settings.EXTRA_APP_PACKAGE, pkg)

    private fun appDetails(packageUri: Uri) = Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS, packageUri)

    companion object {
        const val METHOD_CHANNEL = "alarm_engine"
        const val EVENT_CHANNEL = "alarm_engine/events"
        private const val TAG = "TMinusEngine"
        /** calendarBlue (dark): the brief's Work Outlook colour. */
        private const val TEST_COLOR = 0xFF6AA0F5L

        /** Registers both channels on [messenger]. Plan 4's headless engine calls this too. */
        fun register(messenger: BinaryMessenger, context: Context): AlarmEngineChannel {
            val handler = AlarmEngineChannel(context.applicationContext)
            MethodChannel(messenger, METHOD_CHANNEL).setMethodCallHandler(handler)
            EventChannel(messenger, EVENT_CHANNEL).setStreamHandler(handler)
            return handler
        }
    }
}
```

```dart
///
/// Each engine event reaches Dart once per [AlarmEngine]: whichever of [events]
/// or [drainEvents] sees an event first delivers it, and the other drops it
/// (de-duplicated on type, alertId and atUtcMs).
class AlarmEngine {
  AlarmEngine({MethodChannel? methodChannel, EventChannel? eventChannel})
      : _method = methodChannel ?? const MethodChannel(methodChannelName),
        _eventChannel = eventChannel ?? const EventChannel(eventChannelName);

  static const methodChannelName = 'alarm_engine';
  static const eventChannelName = 'alarm_engine/events';
  static const planVersion = 1;
  static const _rememberedEvents = 1000;

  final MethodChannel _method;
  final EventChannel _eventChannel;
  final Set<String> _seen = <String>{}; // insertion-ordered, so the oldest key goes first
  StreamController<EngineEvent>? _controller;
  StreamSubscription<Object?>? _subscription;

  Future<ApplyResult> applyPlan(List<PlannedAlert> alerts) async {
    final raw = await _method.invokeMapMethod<String, Object?>('applyPlan', {
      'version': planVersion,
      'alerts': [for (final a in alerts) a.toJson()],
    });
    return ApplyResult.fromJson(raw!);
  }

  Future<EngineHealth> getHealth() async {
    final raw = await _method.invokeMapMethod<String, Object?>('getHealth');
    return EngineHealth.fromJson(raw!);
  }

  Future<void> testAlarm(AlertStrength strength, {Duration delay = const Duration(seconds: 5)}) =>
      _method.invokeMethod<void>('testAlarm', {'strength': strength.name, 'delaySec': delay.inSeconds});

  Future<void> openPermissionSettings(PermissionKind kind) =>
      _method.invokeMethod<void>('openPermissionSettings', {'kind': kind.name});

  /// Events queued natively that this instance has not delivered yet. Clears the native queue.
  Future<List<EngineEvent>> drainEvents() async {
    final raw = await _method.invokeListMethod<Object?>('drainEvents') ?? const <Object?>[];
    return [
      for (final event in raw.map(_parse))
        if (_firstSeen(event)) event,
    ];
  }

  /// Live events. Every listener shares one native subscription, so de-duplication runs once.
  Stream<EngineEvent> get events {
    final controller = _controller ??= StreamController<EngineEvent>.broadcast(onListen: _listen, onCancel: _cancel);
    return controller.stream;
  }

  void _listen() {
    _subscription = _eventChannel.receiveBroadcastStream().listen(
      (raw) {
        final event = _parse(raw);
        if (_firstSeen(event)) _controller!.add(event);
      },
      onError: (Object error, StackTrace stack) => _controller!.addError(error, stack),
    );
  }

  Future<void> _cancel() async {
    await _subscription?.cancel();
    _subscription = null;
  }

  static EngineEvent _parse(Object? raw) => EngineEvent.fromJson((raw! as Map).cast<String, Object?>());

  bool _firstSeen(EngineEvent event) {
    if (!_seen.add(event.dedupKey)) return false;
    if (_seen.length > _rememberedEvents) _seen.remove(_seen.first);
    return true;
  }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context

/** Shows and removes alert UI. AndroidAlertPresenter (Task 10) is the real one; tests use a fake. */
interface AlertPresenter {
    /** [alerts] just fired together (one coalesce group). */
    fun present(alerts: List<PlannedAlert>)

    /** The user handled [alerts], or they were acknowledged elsewhere: remove their UI. */
    fun withdraw(alerts: List<PlannedAlert>)

    /** [alerts] rang until the ring timeout. */
    fun missed(alerts: List<PlannedAlert>)
}

/**
 * Every alarm and user action: updates PlanStore and AlarmManager, queues the engine event and
 * tells the presenter. Call on the main thread.
 */
class EngineActions(
    context: Context,
    private val presenter: AlertPresenter,
    private val store: PlanStore = PlanStore(context),
    private val scheduler: AlarmScheduler = AlarmScheduler(context, store),
    private val clock: () -> Long = System::currentTimeMillis,
) {
    private val appContext: Context = context.applicationContext

    /** An alarm went off: collects its coalesce group and presents it. Returns the collected alerts. */
    fun fire(alertId: String): List<PlannedAlert> {
        val t = transition { EngineReducer.fire(it, alertId) }
        if (t.affected.isEmpty()) return emptyList()
        t.toCancel.forEach { scheduler.cancel(it.id) }
        val now = clock()
        t.affected.forEach { emit(EngineEvent.of(EngineEventType.FIRED, it, now)) }
        presenter.present(t.affected)
        return t.affected
    }

    /** [option] null means each alert's notification default (roadmap §5.1). Past choices become +1 min. */
    fun snooze(alertIds: Collection<String>, option: SnoozeOption?) {
        val now = clock()
        val t = transition { s ->
            EngineReducer.snooze(s, alertIds) { a ->
                val chosen = option ?: SnoozeOptions.notificationDefault(now, a.event.startUtcMs)
                SnoozeOptions.untilOrNextMinute(chosen, now, a.event.startUtcMs)
            }
        }
        t.toArm.forEach(scheduler::arm)
        t.affected.zip(t.toArm).forEach { (alert, snooze) ->
            emit(EngineEvent.of(EngineEventType.SNOOZED, alert, now, snooze.fireAtUtcMs))
        }
        withdraw(t.withdrawn)
    }

    /** Dismiss / Stop: ends only these alerts; later alerts of the occurrence still fire (spec §6). */
    fun dismiss(alertIds: Collection<String>) {
        val t = transition { EngineReducer.dismiss(it, alertIds) }
        val now = clock()
        t.affected.forEach { emit(EngineEvent.of(EngineEventType.DISMISSED, it, now)) }
        withdraw(t.withdrawn)
    }

    fun dismissAll(alertIds: Collection<String>) {
        acknowledge(alertIds, EngineEventType.DISMISSED_ALL)
    }

    /** Records the join (counts as Dismiss all) and returns the alert so the caller can open its link. */
    fun join(alertId: String): PlannedAlert? = acknowledge(listOf(alertId), EngineEventType.JOINED).firstOrNull()

    fun missed(alertIds: Collection<String>) {
        val t = transition { EngineReducer.missed(it, alertIds) }
        if (t.affected.isEmpty()) return
        val now = clock()
        t.affected.forEach { emit(EngineEvent.of(EngineEventType.MISSED, it, now)) }
        presenter.missed(t.affected)
    }

    private fun acknowledge(alertIds: Collection<String>, type: EngineEventType): List<PlannedAlert> {
        val t = transition { EngineReducer.acknowledge(it, alertIds) }
        t.toCancel.forEach { scheduler.cancel(it.id) }
        val now = clock()
        t.affected.forEach { emit(EngineEvent.of(type, it, now)) }
        withdraw(t.withdrawn)
        return t.affected
    }

    private fun withdraw(alerts: List<PlannedAlert>) {
        if (alerts.isNotEmpty()) presenter.withdraw(alerts)
    }

    private fun transition(block: (EngineState) -> Transition): Transition =
        store.update { s -> block(s).let { it.state to it } }

    private fun emit(event: EngineEvent) = EngineEvents.emit(appContext, event)
}
```

```kotlin
import java.time.Instant
import java.time.ZoneId
import java.time.format.DateTimeFormatter
import java.util.Locale

/** Every user-visible engine string, in the device's time zone and 12/24-hour setting. */
class AlertText(zone: ZoneId, is24Hour: Boolean, locale: Locale = Locale.getDefault()) {
    private val clockFormat = DateTimeFormatter.ofPattern(if (is24Hour) "HH:mm" else "h:mm a", locale).withZone(zone)

    fun time(utcMs: Long): String = clockFormat.format(Instant.ofEpochMilli(utcMs))

    /** "10:00–11:00" with an en dash. */
    fun range(e: EventSnapshot): String = "${time(e.startUtcMs)}–${time(e.endUtcMs)}"

    /** "Teams", "Boardroom 2" or "Teams · Boardroom 2"; a Teams location text is not repeated. */
    fun where(e: EventSnapshot): String? {
        val parts = mutableListOf<String>()
        if (e.joinUrl != null) parts += "Teams"
        val location = e.location?.trim().orEmpty()
        if (location.isNotEmpty() && !(e.joinUrl != null && location.contains("Teams", ignoreCase = true))) parts += location
        return parts.joinToString(" · ").ifEmpty { null }
    }

    fun detail(e: EventSnapshot): String = listOfNotNull(range(e), where(e)).joinToString(" · ")

    /** "In 10 min · Sprint planning" (brief §10). */
    fun headsUpTitle(a: PlannedAlert, nowUtcMs: Long): String =
        "${Countdown.of(nowUtcMs, a.event.startUtcMs).short()} · ${a.event.title}"

    /** "Starts in 1 min · Sprint planning" (mockup 6a). */
    fun ringingTitle(a: PlannedAlert, nowUtcMs: Long): String =
        "${Countdown.of(nowUtcMs, a.event.startUtcMs).sentence()} · ${a.event.title}"

    fun coalescedTitle(count: Int): String = "$count meetings starting"

    fun coalescedText(alerts: List<PlannedAlert>): String = alerts.joinToString(", ") { it.event.title }

    /** "Missed: Sprint planning (10:00)" (brief §10). */
    fun missedTitle(a: PlannedAlert): String = "Missed: ${a.event.title} (${time(a.event.startUtcMs)})"

    companion object {
        fun forDevice(context: Context) = AlertText(ZoneId.systemDefault(), DateFormat.is24HourFormat(context))
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.app.NotificationManager
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.net.Uri

/** Snooze / Dismiss (Stop) / Dismiss all buttons on engine notifications. Join goes to JoinActivity. */
class NotificationActionReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val ids = intent.getStringArrayListExtra(EXTRA_ALERT_IDS) ?: return
        val actions = EngineActions.create(context)
        when (intent.action) {
            ACTION_SNOOZE -> actions.snooze(ids, null)
            ACTION_DISMISS -> actions.dismiss(ids)
            ACTION_DISMISS_ALL -> actions.dismissAll(ids)
            else -> return
        }
        // Clears the notification even if its alerts were already pruned from PlanStore.
        val notificationId = intent.getIntExtra(EXTRA_NOTIFICATION_ID, NO_NOTIFICATION_ID)
        if (notificationId != NO_NOTIFICATION_ID) {
            context.getSystemService(NotificationManager::class.java).cancel(notificationId)
        }
    }

    companion object {
        const val ACTION_SNOOZE = "io.github.fifothehein.tminus.action.SNOOZE"
        const val ACTION_DISMISS = "io.github.fifothehein.tminus.action.DISMISS"
        const val ACTION_DISMISS_ALL = "io.github.fifothehein.tminus.action.DISMISS_ALL"
        const val EXTRA_ALERT_IDS = "alertIds"
        const val EXTRA_NOTIFICATION_ID = "notificationId"
        /** For the ringing notification, which RingingService owns. */
        const val NO_NOTIFICATION_ID = -1

        fun intent(context: Context, action: String, ids: ArrayList<String>, notificationId: Int): Intent =
            Intent(context, NotificationActionReceiver::class.java)
                .setAction(action)
                .setData(Uri.parse("tminus://action/$notificationId/${Uri.encode(ids.joinToString(","))}"))
                .putStringArrayListExtra(EXTRA_ALERT_IDS, ids)
                .putExtra(EXTRA_NOTIFICATION_ID, notificationId)
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.media.AudioAttributes
import android.provider.Settings
import android.util.Log
import androidx.core.app.NotificationCompat
import io.github.fifothehein.tminus.MainActivity
import io.github.fifothehein.tminus.R

/** Builds and posts every engine notification (spec §7 Firing, brief §10). At most three actions each. */
class NotificationFactory(
    context: Context,
    private val text: AlertText = AlertText.forDevice(context),
    private val clock: () -> Long = System::currentTimeMillis,
) {
    private val appContext: Context = context.applicationContext
    private val manager: NotificationManager = appContext.getSystemService(NotificationManager::class.java)

    fun ensureChannels() {
        val ringing = NotificationChannel(CHANNEL_RINGING, "Ringing alarms", NotificationManager.IMPORTANCE_HIGH).apply {
            description = "Full-screen meeting alarms. The alarm plays its own sound."
            setSound(null, null)
            enableVibration(false)
            lockscreenVisibility = Notification.VISIBILITY_PUBLIC
        }
        val headsUp = NotificationChannel(CHANNEL_HEADS_UP, "Heads-up", NotificationManager.IMPORTANCE_HIGH).apply {
            description = "Reminders before a meeting. Silent when the phone is on silent."
            setSound(
                Settings.System.DEFAULT_NOTIFICATION_URI,
                AudioAttributes.Builder()
                    .setUsage(AudioAttributes.USAGE_NOTIFICATION_EVENT)
                    .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                    .build(),
            )
            enableVibration(true)
            lockscreenVisibility = Notification.VISIBILITY_PUBLIC
        }
        val missed = NotificationChannel(CHANNEL_MISSED, "Missed alarms", NotificationManager.IMPORTANCE_DEFAULT).apply {
            description = "Alarms that rang until they timed out."
        }
        manager.createNotificationChannels(listOf(ringing, headsUp, missed))
    }

    fun postHeadsUp(alerts: List<PlannedAlert>, silent: Boolean = false) {
        if (alerts.isEmpty()) return
        ensureChannels()
        notify(headsUpId(alerts.first().coalesceGroup), headsUp(alerts, silent))
    }

    fun cancelHeadsUp(group: String) = manager.cancel(headsUpId(group))

    fun postMissed(alert: PlannedAlert) {
        ensureChannels()
        notify(missedId(alert.id), missed(alert))
    }

    /** Single: Join (if link) · Snooze · Dismiss all. Coalesced: Dismiss · Snooze all · Dismiss all. */
    fun headsUp(alerts: List<PlannedAlert>, silent: Boolean = false): Notification {
        val ids = ArrayList(alerts.map { it.id })
        val notificationId = headsUpId(alerts.first().coalesceGroup)
        val b = base(CHANNEL_HEADS_UP, alerts.first())
            .setCategory(NotificationCompat.CATEGORY_REMINDER)
            .setPriority(NotificationCompat.PRIORITY_HIGH)
            .setSilent(silent)
            // Swiping a heads-up away is a single Dismiss of what it showed.
            .setDeleteIntent(action(NotificationActionReceiver.ACTION_DISMISS, ids, notificationId))
        if (alerts.size == 1) {
            val a = alerts.single()
            b.setContentTitle(text.headsUpTitle(a, clock())).setContentText(text.detail(a.event))
            if (a.event.joinUrl != null) b.addAction(0, "Join", join(a.id))
            b.addAction(0, "Snooze", action(NotificationActionReceiver.ACTION_SNOOZE, ids, notificationId))
            b.addAction(0, "Dismiss all", action(NotificationActionReceiver.ACTION_DISMISS_ALL, ids, notificationId))
        } else {
            coalesced(b, alerts)
            b.addAction(0, "Dismiss", action(NotificationActionReceiver.ACTION_DISMISS, ids, notificationId))
            b.addAction(0, "Snooze all", action(NotificationActionReceiver.ACTION_SNOOZE, ids, notificationId))
            b.addAction(0, "Dismiss all", action(NotificationActionReceiver.ACTION_DISMISS_ALL, ids, notificationId))
        }
        return b.build()
    }

    fun missed(alert: PlannedAlert): Notification = base(CHANNEL_MISSED, alert)
        .setContentTitle(text.missedTitle(alert))
        .setContentText(text.detail(alert.event))
        .setCategory(NotificationCompat.CATEGORY_REMINDER)
        .setAutoCancel(true)
        .addAction(0, "Open", openApp())
        .build()

    private fun base(channel: String, lead: PlannedAlert): NotificationCompat.Builder =
        NotificationCompat.Builder(appContext, channel)
            .setSmallIcon(R.drawable.ic_stat_tminus)
            .setColor(lead.event.color.toInt())
            .setContentIntent(openApp())
            .setShowWhen(true)
            .setWhen(clock())
            .setVisibility(NotificationCompat.VISIBILITY_PUBLIC)

    private fun coalesced(b: NotificationCompat.Builder, alerts: List<PlannedAlert>) {
        val style = NotificationCompat.InboxStyle()
        alerts.forEach { style.addLine("${it.event.title} · ${text.range(it.event)}") }
        b.setContentTitle(text.coalescedTitle(alerts.size))
            .setContentText(text.coalescedText(alerts))
            .setStyle(style)
    }

    private fun action(action: String, ids: ArrayList<String>, notificationId: Int): PendingIntent =
        PendingIntent.getBroadcast(
            appContext,
            "$action|$notificationId|${ids.joinToString(",")}".hashCode(),
            NotificationActionReceiver.intent(appContext, action, ids, notificationId),
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )

    private fun join(alertId: String): PendingIntent = PendingIntent.getActivity(
        appContext,
        "join|$alertId".hashCode(),
        JoinActivity.intent(appContext, alertId),
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
    )

    private fun openApp(): PendingIntent = PendingIntent.getActivity(
        appContext,
        OPEN_REQUEST_CODE,
        Intent(appContext, MainActivity::class.java).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_SINGLE_TOP),
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
    )

    private fun notify(id: Int, notification: Notification) {
        try {
            manager.notify(id, notification)
        } catch (e: SecurityException) {
            Log.w(TAG, "POST_NOTIFICATIONS not granted; Health reports this", e)
        }
    }

    companion object {
        const val CHANNEL_RINGING = "alarm_ringing"
        const val CHANNEL_HEADS_UP = "heads_up"
        const val CHANNEL_MISSED = "missed"
        const val RINGING_NOTIFICATION_ID = 1001
        private const val OPEN_REQUEST_CODE = 0x5102
        private const val TAG = "TMinusEngine"

        fun headsUpId(group: String): Int = "headsUp|$group".hashCode()

        fun missedId(alertId: String): Int = "missed|$alertId".hashCode()
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context

/** The real AlertPresenter. Task 12 adds the ringing branch for alarm-strength groups. */
class AndroidAlertPresenter(
    context: Context,
    private val store: PlanStore = PlanStore(context),
    private val notifications: NotificationFactory = NotificationFactory(context),
) : AlertPresenter {

    override fun present(alerts: List<PlannedAlert>) {
        notifications.postHeadsUp(alerts)
    }

    override fun withdraw(alerts: List<PlannedAlert>) {
        refreshHeadsUps(alerts)
    }

    override fun missed(alerts: List<PlannedAlert>) {
        alerts.forEach(notifications::postMissed)
        withdraw(alerts)
    }

    /** Re-posts (silently) or cancels each heads-up notification that showed one of [alerts]. */
    private fun refreshHeadsUps(alerts: List<PlannedAlert>) {
        if (alerts.isEmpty()) return
        val presented = store.read().presented
        alerts.map { it.coalesceGroup }.distinct().forEach { group ->
            val remaining = presented.filter { it.coalesceGroup == group }
            if (remaining.isEmpty()) notifications.cancelHeadsUp(group) else notifications.postHeadsUp(remaining, silent = true)
        }
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import java.util.concurrent.CopyOnWriteArraySet

/**
 * The alerts ringing right now, shared in-process by RingingService, AlarmActivity and
 * AndroidAlertPresenter. Main thread only.
 */
object RingingSession {
    private val listeners = CopyOnWriteArraySet<(List<PlannedAlert>) -> Unit>()

    var alerts: List<PlannedAlert> = emptyList()
        private set

    val ids: Set<String> get() = alerts.map { it.id }.toSet()

    fun add(new: List<PlannedAlert>) = set((alerts + new).distinctBy { it.id })

    fun remove(ids: Collection<String>) {
        if (alerts.any { it.id in ids }) set(alerts.filterNot { it.id in ids })
    }

    fun clear() = set(emptyList())

    /** Returns a function that removes [listener]. */
    fun observe(listener: (List<PlannedAlert>) -> Unit): () -> Unit {
        listeners.add(listener)
        return { listeners.remove(listener) }
    }

    private fun set(value: List<PlannedAlert>) {
        alerts = value
        listeners.forEach { it(value) }
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

/** What the alarm screen shows, computed without Android types so it can be unit-tested. */
data class AlarmScreenModel(
    val chip: String,
    val headline: Headline,
    val subtitle: String?,
    val items: List<Item>,
    val snoozeOptions: List<SnoozeOption>,
) {
    val coalesced: Boolean get() = items.size > 1

    /** "Starts in" / "1" / "min", "Started" / "2" / "min ago", or just "Now". */
    data class Headline(val prefix: String?, val number: String, val unit: String?)

    data class Item(
        val alertId: String,
        val title: String,
        val range: String,
        val where: String?,
        val joinUrl: String?,
        val color: Long,
    )

    companion object {
        private const val MINUS = '−'

        fun of(alerts: List<PlannedAlert>, nowUtcMs: Long, text: AlertText): AlarmScreenModel? {
            if (alerts.isEmpty()) return null
            val sorted = alerts.sortedWith(compareBy({ it.event.startUtcMs }, { it.event.title }, { it.id }))
            val earliest = sorted.first().event.startUtcMs
            val lead = sorted.first()
            val chip = if (sorted.size > 1) {
                "${sorted.size} ALARMS"
            } else {
                "${if (lead.strength == Strength.ALARM) "ALARM" else "HEADS-UP"} $MINUS${lead.offsetMinutes}"
            }
            val subtitle = when {
                sorted.size == 1 -> null
                sorted.all { it.event.startUtcMs == earliest } -> "${sorted.size} meetings starting at ${text.time(earliest)}"
                else -> "${sorted.size} meetings starting"
            }
            return AlarmScreenModel(
                chip = chip,
                headline = headline(Countdown.of(nowUtcMs, earliest)),
                subtitle = subtitle,
                items = sorted.map {
                    Item(it.id, it.event.title, text.range(it.event), text.where(it.event), it.event.joinUrl, it.event.color)
                },
                snoozeOptions = SnoozeOptions.visible(nowUtcMs, earliest),
            )
        }

        private fun headline(c: Countdown): Headline = when (c) {
            is Countdown.StartsIn -> Headline("Starts in", c.minutes.toString(), "min")
            Countdown.StartingNow -> Headline(null, "Now", null)
            is Countdown.StartedAgo -> Headline("Started", c.minutes.toString(), "min ago")
        }
    }
}

/** Swaps a design-system calendar colour for its variant in the current theme; other colours pass through. */
object CalendarColors {
    fun forTheme(argb: Int, dark: Boolean, pairs: List<Pair<Int, Int>>): Int {
        val pair = pairs.firstOrNull { (d, l) -> sameRgb(argb, d) || sameRgb(argb, l) } ?: return argb
        return if (dark) pair.first else pair.second
    }

    private fun sameRgb(a: Int, b: Int) = (a and 0xFFFFFF) == (b and 0xFFFFFF)
}
```

`Font(path: String, assetManager: AssetManager, weight: FontWeight)` is in `androidx.compose.ui.text.font` (`AndroidFont.android.kt`) in Compose UI 1.11.4 and carries no opt-in annotation (checked in the 1.11.4 class file).

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context
import android.content.res.AssetManager
import androidx.compose.ui.text.font.Font
import androidx.compose.ui.text.font.FontFamily
import androidx.compose.ui.text.font.FontWeight
import java.io.IOException

/** IBM Plex read from the TTFs Flutter already bundles (pubspec `fonts:`), so nothing is copied into res/font. */
data class AlarmFonts(val sans: FontFamily, val mono: FontFamily) {
    companion object {
        private val weights = listOf(
            FontWeight.Normal to "Regular",
            FontWeight.Medium to "Medium",
            FontWeight.SemiBold to "SemiBold",
        )
        private val families = listOf("ibm-plex-sans" to "IBMPlexSans", "ibm-plex-mono" to "IBMPlexMono")

        fun path(dir: String, base: String, style: String): String = "flutter_assets/assets/fonts/$dir/$base-$style.ttf"

        fun allPaths(): List<String> = families.flatMap { (dir, base) -> weights.map { (_, style) -> path(dir, base, style) } }

        /** Falls back to the system family if any file is missing, so fonts can never crash the alarm screen. */
        fun load(context: Context, exists: (String) -> Boolean = { assetExists(context.assets, it) }): AlarmFonts {
            fun family(dir: String, base: String, fallback: FontFamily): FontFamily {
                val files = weights.map { (weight, style) -> weight to path(dir, base, style) }
                if (!files.all { exists(it.second) }) return fallback
                return FontFamily(files.map { (weight, file) -> Font(file, context.assets, weight) })
            }
            return AlarmFonts(
                sans = family("ibm-plex-sans", "IBMPlexSans", FontFamily.SansSerif),
                mono = family("ibm-plex-mono", "IBMPlexMono", FontFamily.Monospace),
            )
        }

        private fun assetExists(assets: AssetManager, path: String): Boolean = try {
            assets.open(path).close()
            true
        } catch (e: IOException) {
            false
        }
    }
}
```

```kotlin
@Composable
fun AlarmScreen(alerts: List<PlannedAlert>, fonts: AlarmFonts, text: AlertText, callbacks: AlarmCallbacks) {
    var now by remember { mutableLongStateOf(System.currentTimeMillis()) }
    LaunchedEffect(Unit) {
        while (true) {
            delay(1_000)
            now = System.currentTimeMillis()
        }
    }
    var snoozeOpen by remember { mutableStateOf(false) }
    val palette = alarmPalette(isSystemInDarkTheme())
    val type = remember(fonts) { AlarmType(fonts) }
    val model = AlarmScreenModel.of(alerts, now, text) ?: return
    val wash = palette.eventColor(model.items.first().color)

    Box(
        Modifier
            .fillMaxSize()
            .background(
                Brush.verticalGradient(
                    0f to wash.copy(alpha = 0.22f).compositeOver(palette.surface),
                    0.6f to palette.surface,
                    1f to palette.surface,
                ),
            ),
    ) {
        Column(
            Modifier
                .fillMaxSize()
                .systemBarsPadding()
                .padding(horizontal = 24.dp, vertical = 24.dp),
        ) {
            Chip(model.chip, palette, type)
            Spacer(Modifier.height(40.dp))
            Headline(model, palette, type)
            if (model.coalesced) {
                Spacer(Modifier.height(24.dp))
                CoalescedList(model.items, palette, type, callbacks, Modifier.weight(1f))
            } else {
                Spacer(Modifier.height(40.dp))
                EventBlock(model.items.single(), palette, type)
                Spacer(Modifier.weight(1f))
            }
            Spacer(Modifier.height(16.dp))
            if (snoozeOpen) {
                SnoozeChoices(model.snoozeOptions, palette, type) { option ->
                    snoozeOpen = false
                    callbacks.onSnooze(option)
                }
                Spacer(Modifier.height(12.dp))
            }
            if (model.coalesced) {
                CoalescedActions(palette, type, snoozeOpen, { snoozeOpen = !snoozeOpen }, callbacks.onDismissAll)
            } else {
                SingleActions(model.items.single(), palette, type, snoozeOpen, { snoozeOpen = !snoozeOpen }, callbacks)
            }
        }
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.app.KeyguardManager
import android.os.Build
import android.os.Bundle
import android.view.KeyEvent
import android.view.WindowManager
import androidx.activity.ComponentActivity
import androidx.activity.OnBackPressedCallback
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue

/** Full-screen alarm over the lock screen (spec §7, brief §9). Shows RingingSession and closes when it empties. */
class AlarmActivity : ComponentActivity() {
    private var alerts by mutableStateOf<List<PlannedAlert>>(emptyList())
    private var unsubscribe: (() -> Unit)? = null
    private var joining = false

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        showOverLockScreen()
        enableEdgeToEdge()
        onBackPressedDispatcher.addCallback(
            this,
            object : OnBackPressedCallback(true) {
                // Back never dismisses an alarm: use a button or a volume key.
                override fun handleOnBackPressed() = Unit
            },
        )
        alerts = RingingSession.alerts
        if (alerts.isEmpty()) {
            finish()
            return
        }
        unsubscribe = RingingSession.observe { current ->
            alerts = current
            if (current.isEmpty() && !joining) finish()
        }
        val fonts = AlarmFonts.load(this)
        val text = AlertText.forDevice(this)
        setContent {
            AlarmScreen(
                alerts = alerts,
                fonts = fonts,
                text = text,
                callbacks = AlarmCallbacks(
                    onJoin = ::join,
                    onDismiss = { id -> actions().dismiss(listOf(id)) },
                    onDismissAll = { actions().dismissAll(alerts.map { it.id }) },
                    onSnooze = { option -> actions().snooze(alerts.map { it.id }, option) },
                ),
            )
        }
    }

    /** Volume keys act like the notification's Stop (spec §7): a single Dismiss of everything ringing. */
    override fun dispatchKeyEvent(event: KeyEvent): Boolean {
        if (event.keyCode in VOLUME_KEYS) {
            if (event.action == KeyEvent.ACTION_DOWN && event.repeatCount == 0) {
                actions().dismiss(alerts.map { it.id })
            }
            return true
        }
        return super.dispatchKeyEvent(event)
    }

    override fun onDestroy() {
        unsubscribe?.invoke()
        super.onDestroy()
    }

    private fun join(alertId: String) {
        joining = true
        val url = actions().join(alertId)?.event?.joinUrl
        val keyguard = getSystemService(KeyguardManager::class.java)
        when {
            url == null -> finishIfIdle()
            !keyguard.isKeyguardLocked -> {
                JoinActivity.openJoinUrl(this, url)
                finishIfIdle()
            }
            else -> keyguard.requestDismissKeyguard(
                this,
                object : KeyguardManager.KeyguardDismissCallback() {
                    override fun onDismissSucceeded() {
                        JoinActivity.openJoinUrl(this@AlarmActivity, url)
                        finishIfIdle()
                    }

                    override fun onDismissCancelled() = finishIfIdle()

                    override fun onDismissError() = finishIfIdle()
                },
            )
        }
    }

    private fun finishIfIdle() {
        joining = false
        if (alerts.isEmpty()) finish()
    }

    private fun actions() = EngineActions.create(this)

    private fun showOverLockScreen() {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O_MR1) {
            setShowWhenLocked(true)
            setTurnScreenOn(true)
        } else {
            @Suppress("DEPRECATION")
            window.addFlags(WindowManager.LayoutParams.FLAG_SHOW_WHEN_LOCKED or WindowManager.LayoutParams.FLAG_TURN_SCREEN_ON)
        }
        window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
    }

    companion object {
        private val VOLUME_KEYS = setOf(KeyEvent.KEYCODE_VOLUME_UP, KeyEvent.KEYCODE_VOLUME_DOWN, KeyEvent.KEYCODE_VOLUME_MUTE)
    }
}
```

- Behaviour: a fired group with any alarm-strength alert starts the service; the service goes foreground (type `mediaPlayback`) with the ringing notification (full-screen intent → `AlarmActivity`), plays the tone on `USAGE_ALARM` with a 10 %→100 % ramp over 30 s when `gradualVolume`, vibrates when `vibrate`, holds a partial wake lock for timeout + 30 s, and after `ringTimeoutSec` calls `EngineActions.missed` (event `missed` + a Missed notification).     /** Returns the index and result of the first candidate [open] accepts, or null if none does. */
```kotlin
    fun <S, P> firstPlayable(candidates: List<S>, open: (S) -> P): Pair<Int, P>? {
        candidates.forEachIndexed { index, candidate ->
            try {
                return index to open(candidate)
            } catch (e: Exception) {
                // This tone is unusable; try the next one.
            }
        }
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.app.Service
import android.content.Context
import android.content.Intent
import android.content.pm.ServiceInfo
import android.media.AudioAttributes
import android.media.MediaPlayer
import android.media.RingtoneManager
import android.net.Uri
import android.os.Build
import android.os.Handler
import android.os.IBinder
import android.os.Looper
import android.os.PowerManager
import android.os.VibrationAttributes
import android.os.VibrationEffect
import android.os.Vibrator
import android.os.VibratorManager
import android.provider.Settings
import android.util.Log
import androidx.core.app.ServiceCompat
import androidx.core.content.ContextCompat

/**
 * Rings RingingSession: alarm-stream audio with a volume ramp, vibration and a partial wake lock,
 * as a mediaPlayback foreground service (spec §7 Firing). Stops when the session empties, or after
 * the lead alert's ring timeout, which logs `missed` and posts a Missed notification.
 */
class RingingService : Service() {
    private val handler = Handler(Looper.getMainLooper())
    private lateinit var notifications: NotificationFactory
    private var unsubscribe: (() -> Unit)? = null
    private var inForeground = false
    private var alerting = false
    private var player: MediaPlayer? = null
    private var vibrator: Vibrator? = null
    private var wakeLock: PowerManager.WakeLock? = null
    private var volume = 1f

    private val timeout = Runnable {
        EngineActions.create(this).missed(RingingSession.alerts.map { it.id })
    }

    private val ramp = object : Runnable {
        override fun run() {
            volume = (volume + RAMP_STEP).coerceAtMost(1f)
            player?.setVolume(volume, volume)
            if (volume < 1f) handler.postDelayed(this, RAMP_INTERVAL_MS)
        }
    }

    override fun onBind(intent: Intent?): IBinder? = null

    override fun onCreate() {
        super.onCreate()
        notifications = NotificationFactory(this)
        unsubscribe = RingingSession.observe(::onSessionChanged)
    }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val ids = intent?.getStringArrayListExtra(EXTRA_ALERT_IDS).orEmpty().toSet()
        val alerts = PlanStore(this).read().presented.filter { it.id in ids }
        val session = (RingingSession.alerts + alerts).distinctBy { it.id }
        if (!inForeground) {
            // Must happen within seconds of startForegroundService, even if there is nothing to ring.
            notifications.ensureChannels()
            ServiceCompat.startForeground(this, NotificationFactory.RINGING_NOTIFICATION_ID, notifications.ringing(session), foregroundType())
            inForeground = true
        }
        if (session.isEmpty()) {
            stopRinging()
            return START_NOT_STICKY
        }
        RingingSession.add(alerts)
        val lead = session.firstOrNull { it.strength == Strength.ALARM } ?: session.first()
        if (!alerting) startAlerting(lead.sound)
        handler.removeCallbacks(timeout)
        handler.postDelayed(timeout, lead.sound.ringTimeoutSec * 1_000L)
        return START_NOT_STICKY
    }

    override fun onDestroy() {
        unsubscribe?.invoke()
        stopAlerting()
        super.onDestroy()
    }

    private fun onSessionChanged(alerts: List<PlannedAlert>) {
        if (alerts.isEmpty()) stopRinging() else notifications.notifyRinging(alerts)
    }

    private fun stopRinging() {
        stopAlerting()
        ServiceCompat.stopForeground(this, ServiceCompat.STOP_FOREGROUND_REMOVE)
        inForeground = false
        stopSelf()
    }

    private fun startAlerting(sound: Sound) {
        alerting = true
        acquireWakeLock(sound)
        startSound(sound)
        if (sound.vibrate) startVibration()
    }

    private fun stopAlerting() {
        alerting = false
        handler.removeCallbacksAndMessages(null)
        player?.let { mp ->
            try {
                mp.stop()
            } catch (e: IllegalStateException) {
                // Not started yet; release below is enough.
            }
            mp.release()
        }
        player = null
        vibrator?.cancel()
        vibrator = null
        wakeLock?.takeIf { it.isHeld }?.release()
        wakeLock = null
    }

    private fun startSound(sound: Sound) {
        val candidates = listOfNotNull(
            sound.toneUri?.let(Uri::parse),
            RingtoneManager.getActualDefaultRingtoneUri(this, RingtoneManager.TYPE_ALARM),
            Settings.System.DEFAULT_ALARM_ALERT_URI,
            RingtoneManager.getDefaultUri(RingtoneManager.TYPE_RINGTONE),
        ).distinct()
        play(candidates, sound.gradualVolume)
    }

    private fun play(candidates: List<Uri>, gradual: Boolean) {
        val opened = ToneFallback.firstPlayable(candidates, ::openPlayer)
        if (opened == null) {
            Log.w(TAG, "No playable alarm tone; vibrating only")
            return
        }
        val (index, mp) = opened
        if (index > 0) Log.w(TAG, "Tone ${candidates[0]} failed; using ${candidates[index]}")
        volume = if (gradual) RAMP_START else 1f
        mp.setVolume(volume, volume)
        mp.setOnErrorListener { failed, _, _ ->
            failed.release()
            if (player === failed) player = null
            play(candidates.drop(index + 1), gradual) // the tone broke while playing: fall back
            true
        }
        mp.start()
        player = mp
        if (gradual) {
            handler.removeCallbacks(ramp)
            handler.postDelayed(ramp, RAMP_INTERVAL_MS)
        }
    }

    private fun openPlayer(uri: Uri): MediaPlayer {
        val mp = MediaPlayer()
        try {
            mp.setAudioAttributes(
                AudioAttributes.Builder()
                    .setUsage(AudioAttributes.USAGE_ALARM)
                    .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                    .build(),
            )
            mp.setDataSource(this, uri)
            mp.isLooping = true
            mp.prepare()
            return mp
        } catch (e: Exception) {
            mp.release()
            throw e
        }
    }

    private fun startVibration() {
        @Suppress("DEPRECATION")
        val v: Vibrator = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            getSystemService(VibratorManager::class.java).defaultVibrator
        } else {
            getSystemService(Vibrator::class.java)
        }
        if (!v.hasVibrator()) return
        val effect = VibrationEffect.createWaveform(VIBRATION_PATTERN, 0)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
            v.vibrate(effect, VibrationAttributes.createForUsage(VibrationAttributes.USAGE_ALARM))
        } else {
            @Suppress("DEPRECATION")
            v.vibrate(effect, AudioAttributes.Builder().setUsage(AudioAttributes.USAGE_ALARM).build())
        }
        vibrator = v
    }

    private fun acquireWakeLock(sound: Sound) {
        wakeLock = getSystemService(PowerManager::class.java)
            .newWakeLock(PowerManager.PARTIAL_WAKE_LOCK, "tminus:ringing")
            .apply {
                setReferenceCounted(false)
                acquire((sound.ringTimeoutSec + 30) * 1_000L)
            }
    }

    private fun foregroundType(): Int =
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK else 0

    companion object {
        const val EXTRA_ALERT_IDS = "alertIds"
        private const val TAG = "TMinusEngine"
        private const val RAMP_START = 0.1f
        private const val RAMP_STEP = 0.03f // 0.1 → 1.0 in 30 steps of 1 s
        private const val RAMP_INTERVAL_MS = 1_000L
        private val VIBRATION_PATTERN = longArrayOf(0, 800, 600)

        fun start(context: Context, alertIds: List<String>) {
            val intent = Intent(context, RingingService::class.java)
                .putStringArrayListExtra(EXTRA_ALERT_IDS, ArrayList(alertIds))
            ContextCompat.startForegroundService(context, intent)
        }
    }
}
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context
import android.util.Log

/** The real AlertPresenter: alarm groups ring in RingingService, heads-up groups are notifications. */
class AndroidAlertPresenter(
    context: Context,
    private val store: PlanStore = PlanStore(context),
    private val notifications: NotificationFactory = NotificationFactory(context),
    private val startRinging: (Context, List<String>) -> Unit = { ctx, ids -> RingingService.start(ctx, ids) },
) : AlertPresenter {
    private val appContext: Context = context.applicationContext

    override fun present(alerts: List<PlannedAlert>) {
        if (alerts.none { it.strength == Strength.ALARM }) {
            notifications.postHeadsUp(alerts)
            return
        }
        try {
            startRinging(appContext, alerts.map { it.id })
        } catch (e: IllegalStateException) {
            // ForegroundServiceStartNotAllowedException (Android 12+) is an IllegalStateException.
            Log.w(TAG, "Ringing service refused to start; showing a heads-up instead", e)
            notifications.postHeadsUp(alerts)
        }
    }

    override fun withdraw(alerts: List<PlannedAlert>) {
        if (alerts.isEmpty()) return
        RingingSession.remove(alerts.map { it.id })
        refreshHeadsUps(alerts)
    }

    override fun missed(alerts: List<PlannedAlert>) {
        alerts.forEach(notifications::postMissed)
        withdraw(alerts)
    }

    /** Re-posts (silently) or cancels each heads-up notification that showed one of [alerts]. */
    private fun refreshHeadsUps(alerts: List<PlannedAlert>) {
        val presented = store.read().presented
        val ringing = RingingSession.ids
        alerts.map { it.coalesceGroup }.distinct().forEach { group ->
            val remaining = presented.filter { it.coalesceGroup == group && it.id !in ringing }
            if (remaining.isEmpty()) notifications.cancelHeadsUp(group) else notifications.postHeadsUp(remaining, silent = true)
        }
    }

    private companion object {
        const val TAG = "TMinusEngine"
    }
}
```

```kotlin
/**
 * Re-arms every alarm after a reboot (before and after the first unlock) and after an app update

            Intent.ACTION_LOCKED_BOOT_COMPLETED,
```

```kotlin
/**
 * Re-arms after the clock, the time zone or exact-alarm access changes (spec §7). Alarms are absolute

            Intent.ACTION_TIMEZONE_CHANGED,
            ACTION_EXACT_ALARM_PERMISSION_CHANGED,
```

```kotlin
package io.github.fifothehein.tminus.engine

import android.content.Context
import android.content.Intent
import androidx.test.ext.junit.runners.AndroidJUnit4
import androidx.test.platform.app.InstrumentationRegistry
import org.junit.After
import org.junit.Assert.assertEquals
import org.junit.Assert.assertFalse
import org.junit.Assert.assertTrue
import org.junit.Before
import org.junit.Test
import org.junit.runner.RunWith

@RunWith(AndroidJUnit4::class)
class RearmReceiversInstrumentedTest {
    private val context: Context = InstrumentationRegistry.getInstrumentation().targetContext
    private val store = PlanStore(context)
    private val scheduler = AlarmScheduler(context, store)
    private lateinit var saved: EngineState

    @Before
    fun saveAndClear() {
        saved = store.read()
        saved.scheduled.forEach { scheduler.cancel(it.id) }
        store.clear()
    }

    @After
    fun restore() {
        store.read().scheduled.forEach { scheduler.cancel(it.id) }
        store.write(saved)
        scheduler.rearmAll()
    }

    private fun alertAt(id: String, fireAt: Long, strength: Strength) = PlannedAlert(
        id = id,
        occurrenceKey = "instrumented|$id",
        fireAtUtcMs = fireAt,
        offsetMinutes = 1,
        strength = strength,
        sound = Sound.DEFAULT,
        event = EventSnapshot("Instrumented $id", fireAt + MINUTE_MS, fireAt + 31 * MINUTE_MS, null, null, 0xFF6AA0F5L),
        coalesceGroup = CoalesceGroups.groupFor(fireAt),
    )

    private fun seed(): Triple<PlannedAlert, PlannedAlert, PlannedAlert> {
        val now = System.currentTimeMillis()
        val alarm = alertAt("rearm-alarm", now + 2 * HOUR_MS, Strength.ALARM)
        val headsUp = alertAt("rearm-headsup", now + 3 * HOUR_MS, Strength.HEADS_UP)
        val past = alertAt("rearm-past", now - HOUR_MS, Strength.ALARM)
        store.write(EngineState(plan = listOf(alarm, headsUp, past)))
        assertFalse(scheduler.isArmed(alarm))
        return Triple(alarm, headsUp, past)
    }

    private fun assertRearmed(action: String, deliver: (Intent) -> Unit) {
        val (alarm, headsUp, past) = seed()
        deliver(Intent(action))
        assertTrue(action, scheduler.isArmed(alarm))
        assertTrue(action, scheduler.isArmed(headsUp))
        assertFalse(action, scheduler.isArmed(past))
        assertEquals(action, listOf(alarm.id, headsUp.id), store.read().plan.map { it.id })
        listOf(alarm, headsUp).forEach { scheduler.cancel(it.id) }
    }

    @Test
    fun lockedBootCompletedRearmsFromDeviceProtectedStorage() {
        assertRearmed(Intent.ACTION_LOCKED_BOOT_COMPLETED) { BootReceiver().onReceive(context, it) }
    }

    @Test
    fun bootCompletedAndPackageReplacedRearm() {
        assertRearmed(Intent.ACTION_BOOT_COMPLETED) { BootReceiver().onReceive(context, it) }
        assertRearmed(Intent.ACTION_MY_PACKAGE_REPLACED) { BootReceiver().onReceive(context, it) }
    }

    @Test
    fun timeZoneChangeRearmsFutureAlertsAndDropsPastOnes() {
        assertRearmed(Intent.ACTION_TIMEZONE_CHANGED) { TimeChangeReceiver().onReceive(context, it) }
    }

    @Test
    fun timeSetAndExactAlarmPermissionChangeRearm() {
        assertRearmed(Intent.ACTION_TIME_CHANGED) { TimeChangeReceiver().onReceive(context, it) }
        assertRearmed(TimeChangeReceiver.ACTION_EXACT_ALARM_PERMISSION_CHANGED) { TimeChangeReceiver().onReceive(context, it) }
    }

    private companion object {
        const val HOUR_MS = 60 * MINUTE_MS
    }
}
```

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

import '../../app/di.dart';

import '../../core/model/alert.dart';

/// Debug-only controls for the native alarm engine, so it can be exercised on a
/// device before the Health screen (Plan 5) and real sources (Plan 4) exist.
class EngineDebugPanel extends StatefulWidget {
  const EngineDebugPanel({super.key = const Key('engineDebugPanel')});

  @override
  State<EngineDebugPanel> createState() => _EngineDebugPanelState();
}

class _EngineDebugPanelState extends State<EngineDebugPanel> {
  static const _delays = <Duration>[
    Duration(seconds: 5),
    Duration(minutes: 1),
    Duration(minutes: 3),
  ];

  final AlarmEngine _engine = getIt<AlarmEngine>();
  late Future<EngineHealth> _health = _loadHealth();
  Duration _delay = _delays.first;
  String? _status;

  /// The FutureBuilder subscribes only on the next frame; `ignore()` keeps an error that
  /// arrives before then from being reported as unhandled. The builder still sees it.
  Future<EngineHealth> _loadHealth() => _engine.getHealth()..ignore();

  /// Runs [action], shows its message (or the failure) and refreshes the health readout.
  Future<void> _run(Future<String> Function() action) async {
    String status;
    try {
      status = await action();
    } on PlatformException catch (e) {
      status = 'Failed: ${e.message ?? e.code}';
    } on MissingPluginException {
      status = 'Engine not available on this platform';
    }
    if (!mounted) return;
    setState(() {
      _status = status;
      _health = _loadHealth();
    });
  }

  Future<String> _test(AlertStrength strength) async {
    await _engine.testAlarm(strength, delay: _delay);
    return '${strength == AlertStrength.alarm ? 'Alarm' : 'Heads-up'} in ${_label(_delay)}';
  }

  Future<String> _drain() async {
    final events = await _engine.drainEvents();
    if (events.isEmpty) return 'No new engine events';
    return 'Drained ${events.length}: ${events.map((e) => e.type.name).join(', ')}';
  }

  Future<String> _notificationSettings() async {
    await _engine.openPermissionSettings(PermissionKind.notifications);
    return 'Opened notification settings';
  }

  @override
  Widget build(BuildContext context) {
    final textTheme = Theme.of(context).textTheme;
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        SegmentedButton<Duration>(
          segments: [
            for (final d in _delays) ButtonSegment(value: d, label: Text(_label(d))),
          ],
          selected: {_delay},
          onSelectionChanged: (selection) => setState(() => _delay = selection.single),
        ),
        const SizedBox(height: 8),
        Wrap(
          spacing: 8,
          runSpacing: 8,
          children: [
            FilledButton.tonal(
              onPressed: () => _run(() => _test(AlertStrength.headsUp)),
              child: const Text('Test heads-up'),
            ),
            FilledButton(
              onPressed: () => _run(() => _test(AlertStrength.alarm)),
              child: const Text('Test alarm'),
            ),
            OutlinedButton(
              onPressed: () => _run(_notificationSettings),
              child: const Text('Notification settings'),
            ),
            TextButton(onPressed: () => _run(_drain), child: const Text('Drain events')),

            if (health == null) return Text('Loading…', style: textTheme.bodySmall);
            return Column(

        ),

    String two(int v) => v.toString().padLeft(2, '0');
    return '${l.year}-${two(l.month)}-${two(l.day)} ${two(l.hour)}:${two(l.minute)}:${two(l.second)}';

        'exact alarms ${h.canScheduleExactAlarms ? 'on' : 'OFF'}',
        'battery ${h.ignoringBatteryOptimizations ? 'unrestricted' : 'optimised'}',
        'alarm volume ${h.alarmStreamMuted ? 'MUTED' : 'on'}',
      ].join(' · ');
}
```
