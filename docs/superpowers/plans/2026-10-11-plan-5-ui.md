# Plan 5: UI Implementation Plan

> **Execution: lightweight orchestrator, run locally** - the orchestrate skill's agents (dev-worker, scout, review-worker, deep-review) and checks, with no Gate-0 stop, no fresh session per wave and no time booking; waves by dependency, no shared files within a wave, one Gradle job at a time, commit each wave, a negative control for every extra or fix test.

**Goal:** The app people actually use. An Agenda that shows every meeting once, what will ring, when and why, with a toggle, an event sheet and quiet modes (plus a "Mute today" quick-settings tile). Alerts (profiles and rules), Sources (add, re-link, re-pick, remove), Health (permissions, sync freshness, the sync log, upcoming alarms and history), Onboarding and Settings (theme, default profile, merging, export/import). The Fix action on a Feed broken notice opens the right source.

**Architecture:** Screens are `provider` + `ChangeNotifier` controllers over the drift repositories, built under `lib/features/<area>/`. Nothing in the UI plans on its own. `MeetingPlanner` (Task 3) is the one planning path: it reads the cache, merges copies into meetings (Plan 4b's `MeetingMerger`), resolves rules and builds the plan. `SyncService` uses it before `applyPlan`, and the Agenda uses it read-only, so the Agenda shows exactly what the engine was given. Every edit that changes what rings (toggle, override, profile, rule, skip filter, default profile, quiet mode, merge switch, source change) calls `ReplanScheduler.request()`. About 1 s later that runs `SyncService.run(SyncTrigger.edit)`, which plans from the cache and fetches nothing. Android features Flutter lacks go through one new channel, `tminus_ui` (permissions, the alarm-tone picker, opening a link, save/open documents, device info, the install id). The quick-settings tile stores a request in Kotlin and queues a headless `quietTile` run. That run applies the request and re-plans. drift only notifies watchers about writes made in its own isolate, so Kotlin tells the UI engine when a headless sync finishes and the UI marks every table as updated.

**Tech Stack:** Dart 3.13 / Flutter 3.47, `go_router` 18, `provider` 6, `get_it` 9, drift 2.35 (all already in `pubspec.yaml`). No new Dart or Gradle dependency. Kotlin 2.4.0, androidx.core 1.18.0, Robolectric 4.17.

**Spec:** `docs/superpowers/specs/2026-10-06-tminus-design.md` §6 (quiet modes, explainability), §8 (screens), §9 (Health, banners), §10 (secrets, export), §13 (meetings in several sources). Copy and layout: `docs/design-brief.md` §1–§8 and the mockups in `docs/design/` (visuals win over the spec, behaviour follows the spec). Binding contracts: roadmap §2–§4. Plans 2, 3, 4 and 4b in `docs/superpowers/plans/`, and especially Plan 4's "Built differently from this plan (2026-10-09)" and "Notes for Plan 5", and Plan 4b's "Notes for Plan 5" and "Not covered". This plan carries every one of those notes (listed in the Self-review).

**Base:** `main` after Plan 4b (branch `claude/plan-4b-impl-9b39a6`) has merged. Plan 4b was not on `main` when this plan was written. Everything that names Plan 4b's code below follows Plan 4b's design (`docs/superpowers/plans/2026-10-09-plan-4b-multi-source-meetings.md`). Task 1 checks those names against the merged code before anything is built.

## Global Constraints

- Application ID and Kotlin package root: `io.github.fifothehein.tminus`. New Kotlin goes in `.../ui/` (Task 2) and `.../quiet/` (Task 7). New Dart goes in `lib/features/<area>/`, `lib/app/` (services) and, for logic that is not UI, `lib/core/`.
- `minSdk = 26`, `compileSdk`/`targetSdk = flutter.*` (36). **Do not raise compileSdk.** No new Dart package and no new Gradle dependency (decision 1). androidx.core 1.18.0 (already present) supplies `ActivityCompat`, `NotificationManagerCompat`, `IntentCompat` and `PackageInfoCompat`.
- `lib/core/model/alert.dart` and `lib/core/model/planned_alert.dart` are the roadmap §3 contract. **Never edit them and never run `dart format` on them.**
- Run `dart format` only on the files a task lists, never on `lib/` or `test/` as a whole.
- **Log an exception's `runtimeType`, or a `PlatformException`'s `code`, never a message**, in Dart and in Kotlin (`e.javaClass.simpleName`). A message can carry a feed link, a row's values or a file path. A widget never shows `e.toString()` either: a failed action shows fixed text.
- **The ICS link is a secret** (spec §10). It is typed into a field, sent to `SourceAdmin`/`IcsLinkProbe`, and otherwise exists only in flutter_secure_storage. The UI shows it only as `IcsUrl.mask(url)`. It never goes into drift, an export, a log line, a snackbar or a route.
- **One consumer of engine events per isolate** (Plan 4): only `EngineEventRecorder` calls `drainEvents`. The UI reads history from the database.
- **Every edit that changes what rings ends with `getIt<ReplanScheduler>().request()`**, never with a fetching sync. Pull-to-refresh, **Sync now**, adding a source and re-linking one use `SyncService.run` with a fetching trigger (decision 2).
- **Overrides are written on the meeting key** (`item.meeting.key`). Every write goes through `OverrideRepository.rewriteFor`: it starts from the override in effect (the first of the meeting's `lookupKeys`, or `lookupSeriesUids` in series scope, that has one, as Plan 4b's lookup does), writes the result to the meeting key (or the time source's series uid), and deletes the overrides on the other targets. So a field set on a copy key is neither hidden nor brought back (Plan 4b note, decision 9).
- Times are UTC in the model. The screen shows them in `tz.local` with `TimeText` (Task 4), as 24-hour times. No `intl` dependency.
- Copy is English and follows `docs/design-brief.md` word for word where the brief gives the text.
- Widget tests use an in-memory database: `configureDependencies(openDatabase: openTestDatabase)` and `tearDown(getIt.reset)`. Platform channels are mocked with `TestDefaultBinaryMessengerBinding.instance.defaultBinaryMessenger.setMockMethodCallHandler`. A widget test never sleeps: it uses `tester.pump(duration)` or `waitUntil` (`test/core/storage/test_database.dart`).
- Gates at the end of **every** task, from the repo root: `flutter analyze` → `No issues found!`; `flutter test` → `All tests passed!`; and, if any Kotlin changed, the Kotlin unit tests → `BUILD SUCCESSFUL`.
- Kotlin unit tests (one Gradle job at a time). Git Bash: `cd /c/Projects/tminus/android && ./gradlew :app:testDebugUnitTest`. PowerShell: `cd C:\Projects\tminus\android; .\gradlew.bat :app:testDebugUnitTest`. Add `--tests "<fully.qualified.TestClass>"` for one class. A fresh worktree has no `android/gradlew`: copy `gradlew` and `gradlew.bat` from the main checkout, or run `flutter build apk --debug` once.
- Commit messages are one imperative, sentence-case line with no prefix (e.g. `Add the tminus_ui channel and route Fix taps to the source`).
- **Negative controls:** every test added beyond the tests a task names, and every test added for a review fix, is first run against the code without the fix and seen to fail. The worker records that failing run in the job report.
- **Deep review** is marked on each task. It is required for tasks that touch secrets, the database or an exported Android component (Tasks 2, 3, 4, 5, 7, 8, 11, 12, 13, 18).

## Review Focus

1. **The Agenda and the engine agree.** The Agenda must show exactly the alerts the last plan armed: the same meetings, the same keys and the same chips. Expected: both come from `MeetingPlanner.load` (Task 3). Pinned by `the agenda shows the alerts the sync planned` (Task 9) and Task 22 Step 2.
2. **An edit reaches the engine.** A toggle, a profile choice, a rule or a quiet mode must change what rings within seconds, offline too, and without fetching. Expected: `ReplanScheduler` runs one `SyncTrigger.edit` 1 s after the last edit; that run plans from the cache, never fetches, and does not count as a foreground sync. Pinned by Task 3 (`an edit run fetches nothing and keeps lastFinished`) and Task 8 (`three quick requests run one re-plan`), and Task 22 Steps 3 and 6.
3. **What a headless sync writes reaches the open UI.** drift watchers see only their own isolate's writes. Expected: the UI marks every table as updated when Kotlin reports a background sync finished, and on every resume. Pinned by Task 8 (`a background sync signal refreshes every watcher`) and Task 22 Step 9.
4. **The ROUTE extra from another app.** `MainActivity` is exported. A hostile intent can carry any `io.github.fifothehein.tminus.ROUTE`. Expected: only `/sources/<id>` with `[A-Za-z0-9-]{1,64}` (not `add`) is honoured, Flutter's `route` extra and data deep links are off, and Dart sends any path it does not know to the Agenda. A parcel that throws is dropped too. Pinned by Task 2 (`RouteExtraTest`, `UiChannelTest`), Task 12 (`a route that is not a known route goes to the Agenda`, `without debug tools the developer route goes to Settings`) and Task 22 Step 7.
5. **A restore versus an upgrade.** The first Plan 5 start on the user's existing phone has a database and no install id. That is an upgrade, and it must keep everything. A restored backup has a database whose install id differs from this device's. Expected: only the second is treated as a restore. Pinned by Task 8 (`an upgrade keeps every source enabled and marks onboarding done`, `a restore disables sources and clears device state`).
6. **The secret link.** Expected: the probe, the re-link dialog, the source detail, export and every log line keep the link out of drift, logs, the export file and the screen (masked only). Pinned by Task 5 (`a failing probe never repeats the link`), Task 11 (`an export holds no link and no storage key`) and Task 18 (`the source detail shows only the masked link`).
7. **The tile never loses a tap.** Two taps, or a tap during a sync, must leave the quiet state matching the last tap. Expected: the latest request wins; a `quietTile` run already running is followed by another one (`APPEND_OR_REPLACE`); and every sync, of any trigger, applies a waiting request first. Pinned by Task 7 (`QuietStoreTest`) and Task 3 (`a waiting tile request is applied before planning`).
8. **Import is all or nothing.** Expected: an unreadable or invalid file changes nothing. A valid one replaces profiles, rules and settings in one transaction and adds sources in setup state. Pinned by Task 11.

## Decisions

Decided with the user while planning (2026-10-11):

1. **Native glue is our own `tminus_ui` channel**, like `alarm_engine` and `tminus_sync`, with no plugins. `requestPermission {kind: calendar|notifications}` → `granted|denied|permanentlyDenied`. `pickAlarmTone {current}` → `{picked, uri, title}`. `toneTitle {uri}` → `String?`. `openUrl {url}` → `bool` (https only). `openAppDetails`. `createDocument {name, text}` → `bool`. `openDocument` → `String?` (at most 1 MiB). `deviceInfo` → `{versionName, versionCode, manufacturer, sdkInt}`. Registered only on the UI engine. `MainActivity` forwards activity and permission results.
2. **Edits re-plan from the cache.** `SyncTrigger` gains `edit` and `quietTile` (appended), and `SyncTrigger.fetches` is false for both. Such a run takes the lock, applies a waiting tile request, drains, plans from the cache, runs the missed (system) check, calls `applyPlan` and `configure`, evaluates Feed stale, and writes a whole-run log row only when `applyPlan` failed (so edits do not crowd Health's sync log). It does not fetch, does not post or withdraw Feed broken, and does not write `sync.lastFinishedUtcMs`, so a foreground fetch is never skipped because of it. `ReplanScheduler` debounces requests by 1 s and runs at most one re-plan at a time, plus one more if requests arrived meanwhile. It flushes when the app goes to the background.
3. **The quick-settings tile queues a re-plan.** `QuietTileService` (exported, guarded by `BIND_QUICK_SETTINGS_TILE`) stores the latest request (`mute` when the tile shows inactive, `end` when active) and queues an expedited `quietTile` run with `APPEND_OR_REPLACE`. Every sync, whatever its trigger, takes a waiting request first (`tminus_sync.takeQuietRequest`) and applies it. `mute` sets `QuietState.muteToday` for the request's time, and `end` sets `QuietNone`. `configure` gains `quietUntilMs` and `quietText`, so the tile shows the real state without starting Flutter; a waiting request shows as "Muting…" or as inactive. Tile label: `Mute today`. Subtitle: `Until 07:00`, `Paused until 14:00` or `Vacation`. A tap while any quiet mode is active ends it. A tap while a vacation is only planned (not yet covering today) replaces it with Mute today. A tap that is applied after a later in-app change of quiet mode is dropped (`quiet.changedAtUtcMs`).
4. **Backup keeps the database only.** The manifest sets `android:allowBackup="true"`, `android:fullBackupContent="@xml/backup_rules"` (API ≤ 30) and `android:dataExtractionRules="@xml/data_extraction_rules"` (API 31+, for both `cloud-backup` and `device-transfer`). Both list only `app_flutter/tminus.sqlite` and its `-wal` file (include-only: any other file stays out by default, including the secure-storage prefs, feed bodies, PlanStore, the ack store, the event queue and the sync prefs). Consequences, all handled in Task 8:
   - **Install id.** `tminus_sync.installId` (on every engine, so the headless sync can check it too) keeps a random id in `noBackupFilesDir`; the database keeps the id it was written under (`device.installId`). If the database holds no id, this is the first Plan 5 start on this device (a fresh install or an upgrade): the id is stored and nothing else changes. An upgrade with sources marks onboarding done. If the database holds a different id, it was **restored**.
   - **On restore:** clear the occurrence cache, `alert_history`, `sync_log` and every `sync.*` setting (they describe the old phone's alarms and links). Delete the debug source. Disable every ICS source and mark it **needs link**. Disable every phone-calendar source and mark it **needs calendar**, because Android calendar ids differ between phones. Set `ui.restorePending` and clear `ui.onboardingDone`, then store the new id. Profiles, rules, overrides, skip filters, settings and meeting links stay.
   - **Both entry points check.** `main()` runs `RestoreGuard` before anything else, and so does `runHeadlessSync`. After a restore, `SyncBootReceiver` or the periodic sync can start a headless sync before the app is ever opened. That run must not plan from the restored cache, fetch the old phone's calendar ids, or post a Feed broken notice for every feed.
   - **WAL.** On every pause the app runs `PRAGMA wal_checkpoint(PASSIVE)`, so the backed-up main file is nearly always complete. The `-wal` file is backed up too, and `-shm` never is (SQLite rebuilds it).
   - A backup made by a pre-Plan-5 build has no install id. Restored, it looks like an upgrade: each feed then reports `linkMissing` (red, one notice) until it is re-linked. Accepted.
5. **Export/import replaces.** Export writes `tminus-settings-<yyyy-MM-dd>.json` through the system save dialog. The JSON is versioned (`format: "tminus-settings"`, `version: 1`) and holds profiles, rules, skip filters, the default profile, the theme mode, `merge.enabled`, and sources without any link, storage key, Android calendar id or sync state. Debug sources are left out. Import reads through the system open dialog, validates everything first and shows a summary. On confirm, one transaction replaces profiles (user profiles not in the file are deleted through `ProfileRepository.delete`, which clears their references), rules, skip filters, the default profile, the theme and `merge.enabled`. It also adds each imported source as a new, disabled source in setup state (**needs link** / **needs calendar**). Existing sources are never deleted. Then it re-plans.

Made while planning, where the spec, the brief and Plans 4/4b leave a choice:

6. **Background syncs refresh the UI.** `HeadlessFlutterRunner` reports each finished run to the UI engine's `tminus_sync` channel (`syncFinished {trigger, outcome}`), when one is attached. `SyncPlatform.backgroundSyncFinished` streams it, and `AppLifecycle` (Task 8) calls `db.markTablesUpdated(db.allTables)`. It does the same on every resume, as a safety net for a signal sent while no UI engine was attached. That covers Plan 4's note: `missedSystem` rows are written by the sync, not on `EngineEventRecorder.recorded`, so history screens watch the database.
7. **One planning path.** `MeetingPlanner.load({now, fromUtc, toUtc})` reads the enabled sources' cached copies, the links, ranks, `merge.enabled`, the rule set and the acknowledgements, and returns `MeetingPlan {merge, resolved, alerts, rules, sources}`. `SyncService._plan` calls it and then saves `merge.upsert` / `merge.delete`. The Agenda calls it and never writes links. The Agenda's window starts at local midnight today instead of `now − 15 min`; the extra copies are past meetings and change no future alert.
8. **The Agenda toggle** shows `resolved.alerts.isNotEmpty`. Flipping it computes the **natural** state, meaning the resolution with every occurrence override's `enabled` on the meeting's lookup keys removed (`RuleSet.withoutOccurrenceEnabled`). It writes `enabled = null` when the wanted state equals the natural one, else `enabled = wanted`, on the meeting key, through `rewriteFor`: the effective override's profile and custom alerts move with it. So an event silenced by Mute today and switched on is "turned on" (it rings through the quiet mode, spec §6), and switching it back off removes the override.
9. **Override scope in the event sheet:** **This occurrence** writes to `item.meeting.key`. **Whole series** writes to `item.meeting.seriesUid` (the time source's), and is disabled when that is null. **Reset to automatic** drops the profile and custom alerts in that scope from every lookup key or series uid and keeps the effective toggle (`rewriteFor`).
10. **The ROUTE extra** (`io.github.fifothehein.tminus.ROUTE`, Plan 4 note). `MainActivity.getInitialRoute()` returns it on a cold start, and `onNewIntent` passes it on with `NavigationChannel.pushRouteInformation`. Kotlin accepts only `^/sources/(?!add$)[A-Za-z0-9-]{1,64}$` (a source detail, never Add source) and drops anything else, including an extra whose parcel throws. Flutter's own `route` extra and intent-data deep links are switched off. In Dart, the route goes through go_router's normal rules: before onboarding is done it is ignored, an unknown path goes to the Agenda, and an unknown source id shows "This source was removed.".
11. **Checking a link before it is saved.** Onboarding and **Add source** run `IcsLinkProbe.check(url)`: one real fetch with the link held in memory, which stores nothing, posts nothing and logs nothing. It shows "Found N events this week" (occurrences starting in the next 7 days) or the failure message, and for `http://` the warning "This link is not encrypted (http). Anyone on your network can read your calendar. Use the https link if Outlook offers one." (`IcsUrlAccepted.insecure`, Plan 4 decision 6). **Continue** / **Add** then calls `SourceAdmin.addIcsSource` and runs `SyncService.run(SyncTrigger.manual)`. The link field is a URL field with autocorrect and suggestions off (Plan 4 note).
12. **Permissions at runtime.** `READ_CALENDAR` is requested when the user picks **Use a calendar on this phone**, in onboarding and in Add source (Plan 4 decision 16). A permanent denial shows "Calendar access is off. Turn it on in Settings." with **Open settings** (`openAppDetails`). `POST_NOTIFICATIONS` is requested in onboarding's permissions step on API 33+. Below 33 that step opens the notification settings when notifications are off.
13. **Sources needing setup** are disabled and carry `source.setup.<id>` = `link` or `calendar`, so a sync never fetches them or posts a notice for them. Re-linking (`SourceAdmin.updateIcsUrl`) or choosing a calendar (`SourceAdmin.updateDeviceCalendar`) clears the marker and enables the source. The **On** switch is locked while a marker is set.
14. **The theme mode is persisted** (`ui.themeMode` = `system|dark|light`) and loaded before `runApp`, so there is no flash of the wrong theme.
15. **The merge switch** (Settings, "Merge meetings found in more than one calendar", default on) writes `merge.enabled` `'true'`/`'false'` and re-plans (Plan 4b decision 5).
16. **The Agenda replaces the token preview as home.** The token preview and its debug panels stay reachable, in debug builds only, as Settings → **Developer tools** (`/settings/developer`). Plan 4b's device steps still use them.
17. **A phone event titled `Canceled: …` or `Cancelled: …` is marked cancelled**, like ICS (Plan 4b "Not covered"). `ics_core` also exports `isCancelledTitle` (additive to roadmap §2).
18. **The phone calendar picker** lists `queryDeviceCalendars`. Calendars that are already a source show **Already added** and are disabled (Plan 4b note).
19. **Times** are 24-hour local times through `TimeText`: `09:50`, `Tue 6 Oct`, `Synced 4 min ago`, and the countdown `23 min` / `1 h 05` / `Wed 09:50`.
20. **Health** lists the sync log (`SyncLogRepository.watchRecent`, 50 rows) with every `SyncOutcome`. `skipped` (Plan 4) reads "Skipped — another sync was running" in neutral grey. History watches `alert_history` (50 rows). Test alarms (`occurrenceKey` starting `test|`) are labelled **Test**, and `missed` and `missedSystem` are highlighted. The rare double row (`missed` plus `missedSystem` for one alert, Plan 4 note) shows both: it is true information.
21. **Pull-to-refresh** calls `SyncService.run(SyncTrigger.pullToRefresh)` directly (Plan 4 decision 7). A `busy` result shows "Another sync is running. Try again in a minute.", and failed sources show "N calendars could not be read. See Sources."
22. **The tone picker** is the system alarm-tone picker (`RingtoneManager.ACTION_RINGTONE_PICKER`, `TYPE_ALARM`, with the default shown). Its own **Add ringtone** entry covers custom files. Picking the default stores `toneUri = null`. A tone that later goes missing falls back to the default (Plan 3's `ToneFallback`).
23. **The rule editor's live preview** counts the Agenda's upcoming meetings (next 7 days, from `MeetingPlanner`) that the edited rule matches, whatever rules run before it, and lists up to five.
24. **Profiles and rules:** new ids are `p-<12 hex>` / `r-<12 hex>`. Built-in profile names cannot be edited, because explanations quote them, and Silent's alert list is always empty. A user profile can be deleted after a confirmation that says its rules are deleted and its source defaults and overrides are cleared (`ProfileRepository.delete`).

`ui/UiChannel.kt`:

```kotlin
package io.github.fifothehein.tminus.ui

import android.Manifest
import android.app.Activity
import android.content.ActivityNotFoundException
import android.content.Intent
import android.content.pm.PackageManager
import android.media.RingtoneManager
import android.net.Uri
import android.os.Build
import android.os.Handler
import android.os.Looper
import android.provider.Settings
import android.util.Log
import androidx.core.app.ActivityCompat
import androidx.core.app.NotificationManagerCompat
import androidx.core.content.ContextCompat
import androidx.core.content.IntentCompat
import androidx.core.content.pm.PackageInfoCompat
import io.flutter.plugin.common.BinaryMessenger
import io.flutter.plugin.common.MethodCall
import io.flutter.plugin.common.MethodChannel
import java.io.ByteArrayOutputStream
import java.io.IOException
import java.util.concurrent.Executor
import java.util.concurrent.Executors

/**
 * The `tminus_ui` MethodChannel (Plan 5 decision 1): what the screens need from Android that Flutter
 * does not give. Registered on the UI engine only, because it needs the activity. One request that
 * waits for another screen (a permission dialog, a picker) at a time; a second gets `busy`.
 *
 * Errors carry a code only: an exception message can name a file or a link.
 */
class UiChannel internal constructor(
    private val activity: Activity,
    private val io: Executor = Executors.newSingleThreadExecutor(),
) : MethodChannel.MethodCallHandler {
    private val main = Handler(Looper.getMainLooper())
    private var pending: Pending? = null

    private sealed interface Pending { val result: MethodChannel.Result }
    private class PermissionRequest(override val result: MethodChannel.Result, val permission: String) : Pending
    private class TonePick(override val result: MethodChannel.Result) : Pending
    private class CreateDoc(override val result: MethodChannel.Result, val text: String) : Pending
    private class OpenDoc(override val result: MethodChannel.Result) : Pending
    private class TooLarge : IOException()

    override fun onMethodCall(call: MethodCall, result: MethodChannel.Result) {
        try {
            when (call.method) {
                "requestPermission" -> requestPermission(call.string("kind"), result)
                "pickAlarmTone" -> start(TonePick(result), REQ_TONE, toneIntent(call.argument<String>("current")))
                "toneTitle" -> result.success(toneTitle(call.argument<String>("uri")))
                "openUrl" -> result.success(openUrl(call.string("url")))
                "openAppDetails" -> {
                    activity.startActivity(
                        Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS, Uri.fromParts("package", activity.packageName, null)),
                    )
                    result.success(null)
                }
                "createDocument" -> start(
                    CreateDoc(result, call.string("text")),
                    REQ_CREATE,
                    Intent(Intent.ACTION_CREATE_DOCUMENT)
                        .addCategory(Intent.CATEGORY_OPENABLE)
                        .setType(JSON)
                        .putExtra(Intent.EXTRA_TITLE, call.string("name")),
                )
                "openDocument" -> start(
                    OpenDoc(result),
                    REQ_OPEN,
                    Intent(Intent.ACTION_OPEN_DOCUMENT)
                        .addCategory(Intent.CATEGORY_OPENABLE)
                        .setType("*/*")
                        .putExtra(Intent.EXTRA_MIME_TYPES, arrayOf(JSON, "text/plain", "application/octet-stream")),
                )
                "deviceInfo" -> result.success(deviceInfo())
                else -> result.notImplemented()
            }
        } catch (e: IllegalArgumentException) {
            result.error("bad_args", null, null)
        } catch (e: ActivityNotFoundException) {
            result.error("no_activity", null, null)
        } catch (e: Exception) {
            Log.e(TAG, "tminus_ui.${call.method} failed: ${e.javaClass.simpleName}")
            result.error("ui_error", null, null)
        }
    }

    /** True when [requestCode] was ours. */
    fun onRequestPermissionsResult(requestCode: Int, grantResults: IntArray): Boolean {
        if (requestCode != REQ_PERMISSION) return false
        val request = pending as? PermissionRequest ?: return true
        pending = null
        request.result.success(
            when {
                grantResults.isEmpty() -> DENIED // the dialog was interrupted
                grantResults[0] == PackageManager.PERMISSION_GRANTED -> GRANTED
                ActivityCompat.shouldShowRequestPermissionRationale(activity, request.permission) -> DENIED
                else -> PERMANENTLY_DENIED
            },
        )
        return true
    }

    /** True when [requestCode] was ours. */
    fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?): Boolean {
        if (requestCode != REQ_TONE && requestCode != REQ_CREATE && requestCode != REQ_OPEN) return false
        val request = pending ?: return true
        pending = null
        val uri = if (resultCode == Activity.RESULT_OK) data?.data else null
        when (request) {
            is TonePick -> request.result.success(toneResult(resultCode, data))
            is CreateDoc -> if (uri == null) request.result.success(false) else background(request.result, "createDocument") {
                activity.contentResolver.openOutputStream(uri, "wt")!!.use { it.write(request.text.toByteArray(Charsets.UTF_8)) }
                true
            }
            is OpenDoc -> if (uri == null) request.result.success(null) else background(request.result, "openDocument") {
                readCapped(uri)
            }
            is PermissionRequest -> request.result.error("bad_state", null, null)
        }
        return true
    }

    /** The activity is going away: a waiting request will never be answered by Android. */
    fun detach() {
        pending?.result?.error("cancelled", null, null)
        pending = null
    }

    private fun requestPermission(kind: String, result: MethodChannel.Result) {
        val permission = when (kind) {
            "calendar" -> Manifest.permission.READ_CALENDAR
            "notifications" -> {
                if (Build.VERSION.SDK_INT < 33) {
                    // No runtime permission before Android 13: report the switch, and Dart opens settings.
                    result.success(if (NotificationManagerCompat.from(activity).areNotificationsEnabled()) GRANTED else DENIED)
                    return
                }
                Manifest.permission.POST_NOTIFICATIONS
            }
            else -> throw IllegalArgumentException("kind")
        }
        if (ContextCompat.checkSelfPermission(activity, permission) == PackageManager.PERMISSION_GRANTED) {
            result.success(GRANTED)
            return
        }
        if (pending != null) {
            result.error("busy", null, null)
            return
        }
        pending = PermissionRequest(result, permission)
        ActivityCompat.requestPermissions(activity, arrayOf(permission), REQ_PERMISSION)
    }

    private fun start(request: Pending, code: Int, intent: Intent) {
        if (pending != null) {
            request.result.error("busy", null, null)
            return
        }
        pending = request
        try {
            activity.startActivityForResult(intent, code)
        } catch (e: ActivityNotFoundException) {
            pending = null
            request.result.error("no_activity", null, null)
        }
    }

    private fun toneIntent(current: String?): Intent = Intent(RingtoneManager.ACTION_RINGTONE_PICKER)
        .putExtra(RingtoneManager.EXTRA_RINGTONE_TYPE, RingtoneManager.TYPE_ALARM)
        .putExtra(RingtoneManager.EXTRA_RINGTONE_SHOW_DEFAULT, true)
        .putExtra(RingtoneManager.EXTRA_RINGTONE_SHOW_SILENT, false)
        .putExtra(RingtoneManager.EXTRA_RINGTONE_DEFAULT_URI, Settings.System.DEFAULT_ALARM_ALERT_URI)
        .putExtra(
            RingtoneManager.EXTRA_RINGTONE_EXISTING_URI,
            current?.let(Uri::parse) ?: Settings.System.DEFAULT_ALARM_ALERT_URI,
        )

    private fun toneResult(resultCode: Int, data: Intent?): Map<String, Any?> {
        if (resultCode != Activity.RESULT_OK || data == null) return mapOf("picked" to false)
        val uri = IntentCompat.getParcelableExtra(data, RingtoneManager.EXTRA_RINGTONE_PICKED_URI, Uri::class.java)
        val isDefault = uri == null || uri == Settings.System.DEFAULT_ALARM_ALERT_URI
        return mapOf(
            "picked" to true,
            "uri" to if (isDefault) null else uri.toString(),
            "title" to if (isDefault) DEFAULT_TONE_TITLE else (toneTitle(uri.toString()) ?: CUSTOM_TONE_TITLE),
        )
    }

    private fun toneTitle(uri: String?): String? {
        if (uri == null) return DEFAULT_TONE_TITLE
        return runCatching { RingtoneManager.getRingtone(activity, Uri.parse(uri))?.getTitle(activity) }.getOrNull()
    }

    private fun openUrl(url: String): Boolean {
        val uri = Uri.parse(url)
        if (uri.scheme?.lowercase() != "https" || uri.host.isNullOrEmpty()) return false
        return try {
            activity.startActivity(Intent(Intent.ACTION_VIEW, uri).addCategory(Intent.CATEGORY_BROWSABLE))
            true
        } catch (e: ActivityNotFoundException) {
            false
        }
    }

    @Suppress("DEPRECATION") // getPackageInfo(String, Int) is fine for our own package on API 26+
    private fun deviceInfo(): Map<String, Any> {
        val info = activity.packageManager.getPackageInfo(activity.packageName, 0)
        return mapOf(
            "versionName" to (info.versionName ?: ""),
            "versionCode" to PackageInfoCompat.getLongVersionCode(info),
            "manufacturer" to Build.MANUFACTURER,
            "sdkInt" to Build.VERSION.SDK_INT,
        )
    }

    private fun readCapped(uri: Uri): String {
        val out = ByteArrayOutputStream()
        activity.contentResolver.openInputStream(uri)!!.use { input ->
            val buffer = ByteArray(8192)
            while (true) {
                val n = input.read(buffer)
                if (n < 0) break
                out.write(buffer, 0, n)
                if (out.size() > MAX_DOCUMENT_BYTES) throw TooLarge()
            }
        }
        return out.toString(Charsets.UTF_8.name())
    }

    /** Runs file I/O off the main thread and answers on it. */
    private fun background(result: MethodChannel.Result, what: String, work: () -> Any?) {
        io.execute {
            val outcome = runCatching(work)
            main.post {
                outcome.fold(
                    { result.success(it) },
                    { e ->
                        Log.w(TAG, "$what failed: ${e.javaClass.simpleName}")
                        result.error(if (e is TooLarge) "too_large" else "io_error", null, null)
                    },
                )
            }
        }
    }

    private fun MethodCall.string(key: String): String =
        argument<String>(key) ?: throw IllegalArgumentException("$key missing")

    companion object {
        const val NAME = "tminus_ui"
        const val REQ_PERMISSION = 0x5501
        const val REQ_TONE = 0x5502
        const val REQ_CREATE = 0x5503
        const val REQ_OPEN = 0x5504
        const val GRANTED = "granted"
        const val DENIED = "denied"
        const val PERMANENTLY_DENIED = "permanentlyDenied"
        const val DEFAULT_TONE_TITLE = "Default alarm tone"
        const val CUSTOM_TONE_TITLE = "Custom tone"
        const val MAX_DOCUMENT_BYTES = 1 shl 20
        private const val JSON = "application/json"
        private const val TAG = "TMinusUi"

        fun register(messenger: BinaryMessenger, activity: Activity): UiChannel {
            val handler = UiChannel(activity)
            MethodChannel(messenger, NAME).setMethodCallHandler(handler)
            return handler
        }
    }
}
```

```dart
class MeetingPlan {

    required this.alerts,
    required this.rules,
    required this.sources,
  });

  /// Exactly what `applyPlan` gets (sorted by fire time, then id).
  final List<PlannedAlert> alerts;
  final RuleSet rules;

  /// The enabled sources by id, in name order.
  final Map<String, SourceConfig> sources;

/// Ranks as Plan 4b decision 2 defines them: a source whose last fetch failed
/// ranks below a healthy one.
Map<String, SourceRank> sourceRanks(
  Iterable<SourceConfig> enabled,
  Map<String, SourceSyncState?> states,
) => {
  for (final s in enabled)
    s.id: SourceRank(kind: s.kind, failing: states[s.id]?.lastError != null),
};

/// The one planning path. `SyncService` uses it and then stores the link
/// changes; the Agenda uses it read-only, so both show the same meetings,
/// keys and alerts (Review Focus 1).
class MeetingPlanner {
  MeetingPlanner({
    required this.sources,
    required this.occurrences,
    required this.links,
    required this.history,
    required this.settings,
    required this.ruleSets,
    required this.rulesEngine,
  });

  final SourceRepository sources;
  final OccurrenceRepository occurrences;
  final MeetingLinkRepository links;
  final AlertHistoryRepository history;
  final SettingsRepository settings;
  final RuleSetLoader ruleSets;

  /// A new engine per load: it reads `tz.local` as it is now.
  final RulesEngine Function() rulesEngine;

  /// Plans the cached copies of enabled sources that overlap
  /// [fromUtc, toUtc). Writes nothing.
  Future<MeetingPlan> load({
    required DateTime now,
    required DateTime fromUtc,
    required DateTime toUtc,
  }) async {
    final enabled = {
      for (final s in await sources.all())
        if (s.enabled) s.id: s,
    };
    final states = {
      for (final id in enabled.keys) id: await sources.syncState(id),
    };
    final copies = [
      for (final o in await occurrences.between(fromUtc, toUtc))
        if (enabled.containsKey(o.sourceId)) o,
    ];
    final merge = MeetingMerger.merge(
      copies: copies,
      links: await links.all(),
      sources: sourceRanks(enabled.values, states),
      enabled:
          await settings.getString(SyncService.mergeEnabledKey) != 'false',
    );
    final rules = await ruleSets.load();
    final resolved = rulesEngine().resolveAll(merge.meetings, rules);
    return MeetingPlan(
      merge: merge,
      resolved: resolved,
      alerts: buildPlan(
        resolved,
        now: now,
        acknowledgements: await history.acknowledgements(nowUtc: now),
      ),
      rules: rules,
      sources: enabled,
    );
  }
}
```

  ```dart
  /// A tile tap waits in Kotlin until a run takes it; every run takes it
  /// first, so its plan already reflects the tap (Plan 5 decision 3).
  Future<void> _applyQuietRequest(tz.Location location) async {
    final QuietRequest? request;
    try {
      request = await platform.takeQuietRequest();
    } on MissingPluginException {
      return;
    } on PlatformException catch (e) {
      debugPrint('Taking the quiet request failed: ${e.code}');
      return;
    }
    if (request == null) return;
    // A change made in the app after the tap wins over the tap.
    final changed = await settings.quietChangedAt();
    if (changed != null && changed.isAfter(request.atUtc)) return;
    await settings.setQuietStateAt(
      request.mute
          ? QuietState.muteToday(nowUtc: request.atUtc, zone: location)
          : const QuietNone(),
      changedAtUtc: request.atUtc,
    );
  }

  /// When the tile stops showing "on": the end of a mute or pause, or local
  /// midnight after a vacation's last day. Null unless a quiet mode covers
  /// [now] (a vacation that starts next week does not).
  static DateTime? quietEnd(QuietState q, tz.Location zone, DateTime now) {
    if (!q.covers(now, nowUtc: now, zone: zone)) return null;
    return switch (q) {
      QuietUntil(:final untilUtc) => untilUtc,
      Vacation(:final lastDay) => plainUtc(lastDay.addDays(1).startIn(zone)),
      QuietNone() => null,
    };
  }

  /// The tile's subtitle: `Until 07:00`, `Paused until 14:00`, `Vacation`.
  static String? quietTileText(QuietState q, tz.Location zone, DateTime now) {
    if (!q.covers(now, nowUtc: now, zone: zone)) return null;
    if (q is MuteToday) {
      final t = tz.TZDateTime.from(q.untilUtc, zone);
      String two(int v) => v.toString().padLeft(2, '0');
      return 'Until ${two(t.hour)}:${two(t.minute)}';
    }
    return q.label(zone, nowUtc: now);
  }
  ```

```dart
  /// none) and returns the new one. So a field set on a copy key, a profile
  /// while merging was off, say, is carried over instead of being hidden
  /// behind the meeting key, and a cleared field cannot come back from a copy
  /// key (Plan 5 decision 9).
  Future<void> rewriteFor(
    OverrideScope scope,
    List<String> targets,
    EventOverride Function(EventOverride? effective) change,
  ) => _db.transaction(() async {
    final unique = targets.toSet().toList();
    EventOverride? effective;
    for (final t in unique) {
      effective = await find(scope, t);
      if (effective != null) break;
    }
    final next = change(effective);
    assert(next.scope == scope && next.target == unique.first);
    await save(next); // an empty override deletes the row
    for (final t in unique.skip(1)) {
      if (await find(scope, t) != null) await delete(scope, t);
    }
  });
```

`find` skips a row whose custom alerts cannot be read (decision 15 of Plan 2), so such a row is never the effective one; it is still deleted from the other targets.

```dart
import 'package:timezone/timezone.dart' as tz;

import '../model/local_date.dart';

/// 24-hour, English time strings for the screens (Plan 5 decision 19).
/// Instants are UTC; [tz.Location] is the device zone (`tz.local`).
abstract final class TimeText {
  static const weekdays = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];
  static const months = [
    'Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
    'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec',
  ];

  static String _two(int v) => v.toString().padLeft(2, '0');

  /// `09:50`.
  static String hm(DateTime utc, tz.Location zone) {
    final t = tz.TZDateTime.from(utc, zone);
    return '${_two(t.hour)}:${_two(t.minute)}';
  }

  /// `10:00–11:00` (en dash).
  static String range(DateTime startUtc, DateTime endUtc, tz.Location zone) =>
      '${hm(startUtc, zone)}–${hm(endUtc, zone)}';

  /// `Tue 6 Oct`.
  static String day(LocalDate d) {
    final weekday = DateTime.utc(d.year, d.month, d.day).weekday;
    return '${weekdays[weekday - 1]} ${d.day} ${months[d.month - 1]}';
  }

  /// `TUE 6 OCT`, the Agenda's right-hand day label.
  static String dayUpper(LocalDate d) => day(d).toUpperCase();

  /// `Today`, `Tomorrow`, else [day].
  static String dayTitle(LocalDate d, LocalDate today) {
    if (d == today) return 'Today';
    if (d == today.addDays(1)) return 'Tomorrow';
    return day(d);
  }

  /// `just now`, `4 min ago`, `1 h ago`, `2 days ago`.
  static String ago(DateTime pastUtc, DateTime nowUtc) {
    final d = nowUtc.difference(pastUtc);
    if (d.inMinutes < 1) return 'just now';
    if (d.inMinutes < 60) return '${d.inMinutes} min ago';
    if (d.inHours < 24) return '${d.inHours} h ago';
    final days = d.inDays;
    return days == 1 ? '1 day ago' : '$days days ago';
  }

  /// Agenda header: `23 min`, `1 h 05`, or `Wed 09:50` from 24 h on. Rounds
  /// up to whole minutes, so an alert 30 s away reads `1 min`.
  static String countdown(DateTime targetUtc, DateTime nowUtc, tz.Location zone) {
    final seconds = targetUtc.difference(nowUtc).inSeconds;
    final minutes = seconds <= 0 ? 0 : (seconds + 59) ~/ 60;
    if (minutes < 60) return '$minutes min';
    if (minutes < 24 * 60) return '${minutes ~/ 60} h ${_two(minutes % 60)}';
    final t = tz.TZDateTime.from(targetUtc, zone);
    return '${weekdays[t.weekday - 1]} ${hm(targetUtc, zone)}';
  }
}
```

```dart
/// Onboarding's and Add source's "Found 23 events this week" (Plan 5
/// decision 11): one real fetch through [IcsFeedSource], with the link held
/// in memory. Nothing is stored, posted or logged.
class IcsLinkProbe {
  IcsLinkProbe({
    required this.client,
    required this.deviceZone,
    UtcClock? clock,
    this.timeout = const Duration(seconds: 20),
  }) : clock = clock ?? systemUtcNow;

  final http.Client client;
  final String Function() deviceZone;
  final UtcClock clock;
  final Duration timeout;

  Future<ProbeResult> check(String input) async {
    final checked = IcsUrl.check(input);
    if (checked is IcsUrlRejected) return ProbeFailed(checked.message);
    final link = checked as IcsUrlAccepted;
    final now = clock();
    final source = IcsFeedSource(
      config: const SourceConfig(
        id: 'probe',
        name: 'probe',
        color: 0,
        kind: SourceKind.ics,
        secureStorageKey: 'probe',
      ),
      previous: null,
      client: client,
      secrets: _OneLink(link.url),
      bodies: _NoBodies(),
      deviceZone: deviceZone(),
      timeout: timeout,
    );
    final week = now.add(FetchWindow.lookAhead);
    return switch (await source.fetch(FetchWindow.around(now))) {
      SourceFetched(:final occurrences) => ProbeFound(
        url: link.url,
        insecure: link.insecure,
        eventsThisWeek: occurrences
            .where((o) => !o.startUtc.isBefore(now) && o.startUtc.isBefore(week))
            .length,
      ),
      SourceFailed(:final message) => ProbeFailed(message),
    };
  }
}
```

```kotlin
package io.github.fifothehein.tminus.quiet

import android.content.Context

/**
 * The quick-settings tile's side of quiet mode (Plan 5 decision 3). A tap leaves a request here for
 * the next sync to apply (`tminus_sync.takeQuietRequest`); each sync leaves the resulting state here
 * (`configure`), so the tile can draw itself without starting Flutter. One lock for every instance:
 * the tile and the channels each make their own.
 */
class QuietStore(context: Context, private val clock: () -> Long = System::currentTimeMillis) {
    private val prefs = context.applicationContext.getSharedPreferences(PREFS, Context.MODE_PRIVATE)

    data class Request(val action: String, val atMs: Long)
    data class Display(val active: Boolean, val subtitle: String?)

    fun request(action: String) {
        require(action == MUTE || action == END) { "action" }
        synchronized(LOCK) { prefs.edit().putString(KEY_ACTION, action).putLong(KEY_AT, clock()).commit() }
    }

    fun take(): Request? = synchronized(LOCK) {
        val action = prefs.getString(KEY_ACTION, null) ?: return null
        val at = prefs.getLong(KEY_AT, 0L)
        prefs.edit().remove(KEY_ACTION).remove(KEY_AT).commit()
        Request(action, at)
    }

    fun mirror(untilMs: Long?, text: String?) = synchronized(LOCK) {
        prefs.edit().apply {
            if (untilMs == null) remove(KEY_UNTIL) else putLong(KEY_UNTIL, untilMs)
            if (text == null) remove(KEY_TEXT) else putString(KEY_TEXT, text)
        }.commit()
        Unit
    }

    fun display(): Display = synchronized(LOCK) {
        when (prefs.getString(KEY_ACTION, null)) {
            MUTE -> return Display(true, MUTING)
            END -> return Display(false, null)
        }
        val until = prefs.getLong(KEY_UNTIL, 0L)
        if (until > clock()) Display(true, prefs.getString(KEY_TEXT, null)) else Display(false, null)
    }

    /** A tap ends a quiet mode that is on (or about to be), and mutes otherwise. */
    fun actionForTap(): String = if (display().active) END else MUTE

    companion object {
        const val PREFS = "tminus_quiet"
        const val MUTE = "mute"
        const val END = "end"
        const val MUTING = "Muting…"
        private const val KEY_ACTION = "request"
        private const val KEY_AT = "requestAtMs"
        private const val KEY_UNTIL = "untilMs"
        private const val KEY_TEXT = "text"
        private val LOCK = Any()
    }
}
```

```kotlin
object BackgroundSyncSignal {
    private val listeners = mutableSetOf<(String, String) -> Unit>()

    fun add(listener: (String, String) -> Unit) { listeners += listener }
    fun remove(listener: (String, String) -> Unit) { listeners -= listener }

    fun finished(trigger: String, outcome: String) {
        listeners.toList().forEach { listener ->
            try {
                listener(trigger, outcome)
            } catch (e: Exception) {
                Log.w("TMinusSync", "Background sync signal failed: ${e.javaClass.simpleName}")
            }
        }
    }
}
```

```dart
import 'dart:async';

import 'package:flutter/foundation.dart' show debugPrint;

import '../core/sync/sync_service.dart';

/// Turns UI edits into re-plans (Plan 5 decision 2). Each [request] restarts
/// a short timer, so a burst of edits makes one run. At most one run is in
/// flight; requests during it make exactly one more.
class ReplanScheduler {
  ReplanScheduler({
    required this.replan,
    this.delay = const Duration(seconds: 1),
  });

  /// `SyncService.run(SyncTrigger.edit)` in the app.
  final Future<Object?> Function() replan;
  final Duration delay;

  Timer? _timer;
  Future<void>? _running;
  bool _again = false;

  void request() {
    _timer?.cancel();
    _timer = Timer(delay, _fire);
  }

  /// Runs a pending request now, then waits for every run to finish. The
  /// app calls it when it goes to the background.
  Future<void> flush() async {
    if (_timer?.isActive ?? false) {
      _timer!.cancel();
      _fire();
    }
    while (_running != null) {
      await _running;
    }
  }

  void dispose() => _timer?.cancel();

  void _fire() {
    _timer = null;
    if (_running != null) {
      _again = true;
      return;
    }
    _running = _loop().whenComplete(() => _running = null);
  }

  Future<void> _loop() async {
    do {
      _again = false;
      try {
        final report = await replan();
        // A run that never got the lock planned nothing: the sync that held
        // it may have read the rules before this edit. Go again.
        if (report is SyncReport && report.outcome == SyncRunOutcome.busy) {
          _again = true;
        }
      } catch (e) {
        debugPrint('Re-planning failed: ${e.runtimeType}');
      }
    } while (_again);
  }
}
```

```dart
    );
    _signal ??= platform.backgroundSyncFinished.listen(

      debugPrint('WAL checkpoint failed: ${e.runtimeType}');
    }
  }

    _listener = null;
```

```dart
/// Today (always), then each later local day that has meetings, up to the
/// end of the fetch window. All-day meetings first, then by start, then key.
List<AgendaDay> groupByDay(
  List<AgendaItem> items, {
  required DateTime now,
  required tz.Location zone,
}) {
  final today = LocalDate.of(now, zone);
  final byDay = <LocalDate, List<AgendaItem>>{today: []};
  for (final i in items) {
    final d = LocalDate.of(i.meeting.startUtc, zone);
    if (d.compareTo(today) < 0) continue; // LocalDate has no <; the cache holds up to an hour back
    (byDay[d] ??= []).add(i);

  final days = byDay.keys.toList()..sort();
  return [
    for (final d in days)
      AgendaDay(
        date: d,
        title: TimeText.dayTitle(d, today),
        label: TimeText.dayUpper(d),
        items: byDay[d]!..sort(_byAllDayStartKey),
      ),
  ];
}
```

```dart
class HealthMonitor extends ChangeNotifier {
  HealthMonitor({
    required this.engine,
    required this.statuses,
    this.period = const Duration(minutes: 1),
  });

  final AlarmEngine engine;
  final SourceStatusLoader statuses;
  final Duration period;
  HealthReport? _report;
  Timer? _timer;
  AppLifecycleListener? _listener;

  HealthReport? get report => _report;

  void start() {
    _listener ??= AppLifecycleListener(
      onResume: () {
        unawaited(refresh());
        _timer ??= Timer.periodic(period, (_) => unawaited(refresh()));
      },
      onPause: () {
        _timer?.cancel();
        _timer = null;
      },
    );
    _timer ??= Timer.periodic(period, (_) => unawaited(refresh()));
    unawaited(refresh());
  }

  Future<void> refresh() async {
    EngineHealth? health;
    try {
      health = await engine.getHealth();
    } on MissingPluginException {
      health = null;
    } on PlatformException catch (e) {
      debugPrint('getHealth failed: ${e.code}');

    List<SourceStatus> sources = const [];
    try {
      sources = await statuses.all();
    } catch (e) {
      debugPrint('Reading the sources failed: ${e.runtimeType}');
    }
    _report = buildHealthReport(health, sources);
    notifyListeners();
  }

  @override
  void dispose() {
    _timer?.cancel();
    _listener?.dispose();
    super.dispose();
  }
}
```

```dart
import 'dart:async';

import 'package:flutter/foundation.dart';

import '../core/storage/app_settings.dart';

/// Whether onboarding is done, for the router's redirect. Loaded before
/// `runApp`, then kept current from the database.
class OnboardingGate extends ChangeNotifier {
  OnboardingGate(this._settings);

  final AppSettings _settings;
  StreamSubscription<bool>? _sub;
  bool _done = false;

  bool get done => _done;

  /// Never throws. A database that cannot be read counts as done, so the
  /// user lands on the Agenda (which shows the problem) rather than being
  /// trapped in onboarding.
  Future<void> load() async {
    try {
      _done = await _settings.onboardingDone();
    } catch (e) {
      debugPrint('Reading onboarding state failed: ${e.runtimeType}');
      _done = true;
    }
    _sub ??= _settings.watchOnboardingDone().listen(
      (v) {
        if (v == _done) return;
        _done = v;
        notifyListeners();
      },
      onError: (Object e) =>
          debugPrint('Watching onboarding state failed: ${e.runtimeType}'),
    );
  }

  @override
  void dispose() {
    unawaited(_sub?.cancel());
    super.dispose();
  }
}
```

```kotlin
@RunWith(RobolectricTestRunner::class)
class BackupRulesTest {
    private val app = RuntimeEnvironment.getApplication()

    /** (section, domain, path) for every include and exclude in an XML resource. */
    private fun rules(resId: Int): List<Triple<String, String, String>> {
        val out = mutableListOf<Triple<String, String, String>>()
        val xml = app.resources.getXml(resId)
        var section = ""
        while (xml.next() != XmlPullParser.END_DOCUMENT) {
            if (xml.eventType != XmlPullParser.START_TAG) continue
            when (xml.name) {
                "cloud-backup", "device-transfer" -> section = xml.name
                "include", "exclude" -> out += Triple(
                    "$section/${xml.name}",
                    xml.getAttributeValue(null, "domain"),
                    xml.getAttributeValue(null, "path"),
                )
            }
        }
        return out
    }

    private val database = listOf("root" to "app_flutter/tminus.sqlite", "root" to "app_flutter/tminus.sqlite-wal")

    @Test
    fun `both sections include only the database`() {
        val r = rules(R.xml.data_extraction_rules)
        for (section in listOf("cloud-backup", "device-transfer")) {
            assertEquals(database, r.filter { it.first == "$section/include" }.map { it.second to it.third })
        }
        assertTrue(r.none { it.first.endsWith("/exclude") })
    }

    @Test
    fun `the pre-12 rules include only the database`() {
```

```dart
/// Pull-to-refresh's one-line result (Plan 5 decision 21); null = say nothing.
String? pullMessage(SyncReport r) {
  if (r.outcome == SyncRunOutcome.busy) {
    return 'Another sync is running. Try again in a minute.';
  }
  final failed = r.sources.where((s) => s.outcome.severity != OutcomeSeverity.ok).length;
  if (failed == 0) return null;
  return failed == 1
      ? '1 calendar could not be read. See Sources.'
      : '$failed calendars could not be read. See Sources.';
}

class AgendaController extends ChangeNotifier {
  AgendaController({
    required this.loader,
    required this.db,
    required this.overrides,
    required this.settings,
    required this.rulesEngine,
    required this.replan,
    required this.runSync,
    this.tick = const Duration(seconds: 30),
  });

  final AgendaLoader loader;
  final AppDatabase db;
  final OverrideRepository overrides;
  final SettingsRepository settings;
  final RulesEngine Function() rulesEngine;
  final ReplanScheduler replan;
  final SyncRunner runSync;
  final Duration tick;

  AgendaSnapshot? _snapshot;
  bool _failed = false;
  StreamSubscription<Object?>? _updates;
  Timer? _ticker;
  Timer? _debounce;

  AgendaSnapshot? get snapshot => _snapshot;
  bool get failed => _failed;

  /// Reloads on any table write in this isolate (and on AppLifecycle's
  /// refresh after a background sync), and every [tick] for the countdown,
  /// the now line and quiet modes that end.
  void start() {
    _updates ??= db.tableUpdates().listen((_) => _soon());
    _ticker ??= Timer.periodic(tick, (_) => _soon());
    unawaited(reload());
  }

  void _soon() {
    _debounce?.cancel();
    _debounce = Timer(const Duration(milliseconds: 100), () => unawaited(reload()));
  }

  Future<void> reload() async {
    try {
      _snapshot = await loader.load();
      _failed = false;
    } catch (e) {
      debugPrint('Loading the agenda failed: ${e.runtimeType}');
      _failed = true;
    }
    notifyListeners();
  }

  /// Plan 5 decision 8.
  Future<void> setOn(AgendaItem item, bool on) async {
    final snap = _snapshot;
    if (snap == null) return;
    final keys = item.meeting.lookupKeys;
    final natural = rulesEngine()
        .resolve(item.meeting, snap.rules.withoutOccurrenceEnabled(keys))
        .alerts
        .isNotEmpty;
    final enabled = enabledToWrite(wantOn: on, naturalOn: natural);
    await overrides.rewriteFor(
      OverrideScope.occurrence,
      [item.meeting.key, ...keys],
      (e) => EventOverride(
        scope: OverrideScope.occurrence,
        target: item.meeting.key,
        profileId: e?.profileId,
        customAlerts: e?.customAlerts,
        enabled: enabled,
      ),
    );
    replan.request();
  }

  Future<String?> pullToRefresh() async =>
      pullMessage(await runSync(SyncTrigger.pullToRefresh));

  Future<void> endQuiet() async {
    await settings.setQuietStateAt(const QuietNone(), changedAtUtc: systemUtcNow());
    replan.request();
  }

  @override
  void dispose() {
    unawaited(_updates?.cancel());
    _ticker?.cancel();
    _debounce?.cancel();
    super.dispose();
  }
}
```

```dart
String quietBannerText(QuietState q, DateTime now, tz.Location zone) {
  final today = LocalDate.of(now, zone);
  String when(DateTime utc) {
    final d = LocalDate.of(utc, zone);
    final hm = TimeText.hm(utc, zone);
    if (d == today) return 'today $hm';
    if (d == today.addDays(1)) return 'tomorrow $hm';
    return '${TimeText.day(d)} $hm';
  }
  return switch (q) {
    MuteToday(:final untilUtc) => 'Muted until ${when(untilUtc)}',
    PausedUntil(:final untilUtc) => 'Paused until ${when(untilUtc)}',
    Vacation(:final firstDay, :final lastDay) => firstDay >= today.addDays(1)
        ? 'Vacation from ${TimeText.day(firstDay)}'
        : 'Vacation until ${TimeText.day(lastDay)}',
    QuietNone() => '',
  };
}
```

```dart
class EventSheetController extends ChangeNotifier {
  EventSheetController({
    required this.item,
    required this.overrides,
    required this.profiles,
    required this.replan,
    required this.ui,
  });

  final AgendaItem item;
  final OverrideRepository overrides;
  final ProfileRepository profiles;
  final ReplanScheduler replan;
  final UiPlatform ui;

  SheetScope scope = SheetScope.occurrence;
  List<AlertProfile> allProfiles = const [];
  EventOverride? current; // the first override in this scope among the lookup targets

  bool get canUseSeries => item.meeting.seriesUid != null;

  OverrideScope get _scope =>
      scope == SheetScope.occurrence ? OverrideScope.occurrence : OverrideScope.series;

  /// Where a new override goes: the meeting key, or the time source's series.
  String get _target =>
      scope == SheetScope.occurrence ? item.meeting.key : item.meeting.seriesUid!;

  /// Every target an override in this scope may sit on (Plan 4b note).
  List<String> get _targets => scope == SheetScope.occurrence
      ? item.meeting.lookupKeys
      : item.meeting.lookupSeriesUids;

  /// The radio selection: the override's profile, else what resolution
  /// picked. 'custom' when the override has custom alerts and no profile.
  String get selectedProfileId =>
      current?.profileId ??
      (current?.customAlerts?.isNotEmpty == true
          ? 'custom'
          : item.resolved.profile.id);

  Future<void> load() async {
    allProfiles = await profiles.all();
    current = null;
    for (final t in _targets) {
      final o = await overrides.find(_scope, t);
      if (o != null && (o.profileId != null || o.customAlerts != null)) {
        current = o;
        break;
      }
    }
    notifyListeners();
  }

  Future<void> setScope(SheetScope s) async {
    if (s == SheetScope.series && !canUseSeries) return;
    scope = s;
    await load();
  }

  Future<void> chooseProfile(String profileId) =>
      _write(profileId: profileId, customAlerts: null);

  Future<void> setCustomAlerts(List<AlertSpec> alerts) =>
      _write(profileId: current?.profileId, customAlerts: alerts);

  /// "Reset to automatic": drops profile and custom alerts in this scope on
  /// every lookup target; an Agenda toggle (`enabled`) stays.
  Future<void> reset() => _rewrite(
    (e) => EventOverride(scope: _scope, target: _target, enabled: e?.enabled),
  );

  Future<void> _write({String? profileId, List<AlertSpec>? customAlerts}) =>
      _rewrite(
        (e) => EventOverride(
          scope: _scope,
          target: _target,
          profileId: profileId,
          customAlerts: customAlerts,
          enabled: e?.enabled, // the effective toggle, wherever it sat
        ),
      );

  Future<void> _rewrite(EventOverride Function(EventOverride?) change) async {
    await overrides.rewriteFor(_scope, [_target, ..._targets], change);
    replan.request();
    await load();
  }

  /// False when nothing could open the link.
  Future<bool> join() async {
    final url = item.meeting.joinUrl;
    return url != null && await ui.openUrl(url);
  }
}
```

```dart
/// The next time [time] occurs in [zone] after [now]: today if still ahead,
/// else tomorrow. A DST gap is resolved by TZDateTime's normalisation.
DateTime pauseUntil(TimeOfDay time, DateTime now, tz.Location zone) {
  final local = tz.TZDateTime.from(now, zone);
  var at = tz.TZDateTime(zone, local.year, local.month, local.day, time.hour, time.minute);
  if (!at.isAfter(local)) {
    at = tz.TZDateTime(zone, local.year, local.month, local.day + 1, time.hour, time.minute);
  }
  return plainUtc(at);
}
```
